开源 · 自托管 · AI 跑团

AI 跑团工具：让 AI 坐上 KP 的位置，把故事跑下去。

面向 COC7 的开源、自托管 AI 跑团平台：AI 守秘人推进剧情，规则书知识库回答规则问题，剧本编辑器把 Word / PDF 模组变成可玩模组，角色卡与内置编辑器管住每一点技能——剧本、账号与聊天记录全部落在你自己的机器上。

跑团引擎，连同内容工具

引擎在后台，剧本、角色卡与知识库在你自己手里。

它不是一个只会续写剧情的聊天框。叙事与检定交给引擎，内容交给内置的剧本编辑器、世界书、角色卡编辑器与规则书知识库——两边分开，跑团才推得下去。

01

AI KP，不抢走规则

自然语言叙事与结构化状态分开处理。模型负责讲故事，引擎让检定结果、技能值与角色卡真正落地。

02

一张实时多人桌

房间码邀请、成员列表、角色变更实时同步、正在输入提示。页面和实时聊天共用同一个端口，网络环境受限时也能保持同步。

03

世界书会记得

命中触发词直接激活，未命中回退 BM25 + 向量检索；支持常驻条目、分层、概率、粘滞与冷却轮数，AI 只读到它此刻该读的部分。

04

剧本：文档丢进来就能玩

Word / PDF / Markdown 模组按标题分节语义切块并建索引，导入完成即可开团；也可以先让 AI 转成结构化剧本，你审阅修改后再发布。「直接导入」与「审核导入」两条路径都在。

05

内置剧本编辑器

场景卡、结局、时间线、NPC、怪物与道具在同一个界面里编排，可配封面与简介。只有改动剧本内容才会生成新版本；改标题、作者、封面这类基础信息既不升版本、也不重算索引。

06

COC7 角色卡与检定

属性、技能、武器、专精与本地化技能名一应俱全；检定名会对照 character_skills.json（含专精与中文变体）校验，未知名直接拒绝并提示。聊天里的 1D100 结果直接写回卡上，失败 / 成功 / 困难 / 极难都有反馈。

07

内置角色卡编辑器

不用手写 JSON：在页面里直接建卡、改卡、分配技能点。改动技能上限会按最终值裁剪所有点数；带专精的技能在右侧选好专精再切换基础值；技能基础值支持「房规 > 管理员默认 > 规则书默认」三级覆盖。

08

规则书知识库

管理员上传 COC7 规则文本（.txt / .md / .doc / .docx）建成立即生效的检索库。玩家问「这个法术怎么算」时，AI 从你的规则书里找依据再回答，而不是凭记忆编。

明亮 暗色 赛博档案 秘典 · 羊皮纸 界面主题可随时切换，并记住你的选择

单进程运行，不需要 Docker 也能跑。预置 DeepSeek / OpenAI / 阿里云百炼 / SiliconFlow / OpenRouter / LM Studio 六家平台，也支持任意 OpenAI 兼容接口。

本次更新 · v0.5.3b

这一版，把管理和成本也补上了。

除了跑团本身，这次更新重点在「谁可以改什么」和「这局花了多少」，以及让桌面上的骰子更好看。

01

网站 Agent 能动手了

用自然语言查看和修改网站设置、改自己的昵称与邮箱、搜索或清理房间消息。所有写操作先弹确认卡片；设置仅管理员可改，网络与 Agent 自身配置仅 Owner 可改，密钥字段读取打码、写入拒绝。

02

房间花了多少，一眼看到

每个房间单独累计 token 与花费，小字显示在房间右上角和房间管理页。金额按你在 AI 平台设置里填写的模型输入/输出单价与币种计算，只有房主与房间管理员可见。

03

3D 骰子，全桌同步

玩家投掷的 3D 动画会同步给房间里所有人，轨迹一致；结果默认保留 3D 骰桌，实例过多或刷新页面后自动降级为 2D 平铺结果，兼顾观感与性能。

04

房间内嵌控制台

房间页内置只显示本房间日志的控制台，房主、房间管理员与网站管理员可用；日志随房间目录持久保存，并在归档时一并归档，不会把站点级命令暴露给房内。

05

配置分层，注释不再丢

配置统一收进 general.toml，支持「代码默认 < 模板 < 用户配置 < 环境变量 < 命令行」五层优先级；写入时保留注释与键序，部署用环境变量或 --set 锁定的键不会被界面或 Agent 覆盖。

06

解压即用，一键启动

发布包内置构建好的前端与自托管指南，Windows 双击 start.cmd 会自动准备 Python、依赖与运行环境；首次打开弹出部署向导，选平台、填 Key、创建 Owner 即可开团。

界面预览

六项能力，六张真实界面。

房间聊天、剧本编辑器、世界书、COC7 角色卡、角色卡编辑器与规则书知识库，全部照程序的实际界面绘制。

叙事，与后果

叙事可以自由，状态必须可信。

玩家看到的是干净的叙事，背后每一次检定、技能变动与存档都由引擎处理。

  • 检定先掷骰，结果再被叙述。KP 不会先写好结局再补一个骰点。
  • 技能上限改动后按最终值裁剪所有技能点数，不会留下越界的分配。
  • 剧情不会丢。聊天记录持久保存，可打回档节点，也可按周期自动存档。
  • 中途换剧本也不乱。换成同一剧本的最新版本可继承剧情进度，换别的剧本则重置。

两种记忆

「世界书」装的是这个剧本的线索、NPC 与触发器；「规则书知识库」装的是 COC7 规则本身。两者分开检索——剧情线索不会被规则条文挤掉，规则问题也不用你现场翻书。

规则文本支持 .txt / .md / .doc / .docx，上传后立即生效；换一份规则书不用重跑剧本。

随处部署

不用云服务器，也能让朋友连上。

程序可以配合内网穿透等方式使用：在一台普通电脑上跑起来，把地址分享出去，朋友就能加入。零成本、无需云服务器，也不用先准备域名和证书。

  • 同一台电脑：运行 python server.py，浏览器打开 127.0.0.1:8086，先自己开一局。
  • 同一个 Wi-Fi：朋友打开启动日志里的局域网地址就能加入，记得放行防火墙端口。
  • 异地联机：用内网穿透把本机地址映射出去，把得到的外网地址发给朋友即可，不必购买云服务器。
  • 长期使用前，先设置自己的密钥：$env:AI_TRPG_SECRET_KEY，不要沿用默认开发密钥。

常见问题

上手前可能想知道。

打开页面是空白的？

前端没有构建。执行 npm install && npm run build:frontend，或者改用已经带构建产物的 release 压缩包。

朋友连不上？

依次检查三件事：主机防火墙有没有放行端口、IP 对不对（异地组网要用虚拟网卡 IP）、启动日志里有没有对方能访问到的 listening 地址。

AI 不回复，或者只回复一半？

多数是模型接口超时。可以在设置页调大「AI 请求超时」和「最大工具调用轮数」，再确认 API Key 与模型 ID 没写错。

扫描版 PDF 导进来没有内容？

默认只处理文本型 PDF。扫描件需要额外装 OCR 依赖（PaddleOCR），见开发文档里的进阶可选项。

改了剧本标题或封面，版本号为什么没变？

这是刻意的。标题、作者、推荐人数、简介、封面都属于基础信息，改它们不会升版本、也不会重算索引；只有改动剧本内容才会生成新版本。

AI 跑团是什么？

AI 跑团就是用 AI 当守秘人（KP）来带的跑团。这里把叙事交给模型、把检定与角色卡交给引擎：模型负责讲故事、扮演 NPC，引擎让 1D100 的结果真正落在角色卡上。你不用备课，也不用凑齐固定的时间。

线上跑团怎么和朋友一起玩？

房主在自己电脑上运行程序，新建房间后把房间码发给朋友；朋友用浏览器打开同一个地址、输入房间码就能加入。页面和实时聊天共用同一个端口，再配合内网穿透，异地朋友也能连上，不需要云服务器。

怎么看一局跑了多少 token、花了多少钱？

房主与房间管理员会在房间右上角、房间管理页看到本房间累计的 token 与花费。金额按「AI 平台设置」里每个模型的输入/输出单价和平台币种计算；没填单价的模型只统计 token，金额显示「未配置单价」。数据只对本房间可管理的人可见。

网站 Agent 会不会被普通用户用来改站点设置？

不会。Agent 的每次写操作都会先弹出确认卡片，后端在生成和执行两步分别鉴权：网站设置只有管理员与 Owner 能用，网络与 Agent 自身配置只有 Owner 能改，密钥字段读取时打码、写入时拒绝；房间消息的删除与清空还要求房主或房间管理员身份。权限不足时会直接拒绝并写入日志。

有没有免费的跑团工具？

帷幕（The Veil）本身就是开源免费的跑团工具（Apache-2.0），在 aitrpg.top 或 release 页下载解压即可运行。唯一可能产生费用的是你自己选的 AI 模型接口，也可以先用本地模型跑；服务器就用你自己的电脑。
