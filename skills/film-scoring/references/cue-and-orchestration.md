# Cue 结构与编配（Cue Architecture & Orchestration）

## 1. 五段 cue

| 段落 | 目标 | 小节数（典型） | 必须发生的事 | 禁止 |
| --- | --- | --- | --- | --- |
| bed 铺垫 | 建立空间与低音 | 6–8 | pedal/低音进入；稀疏动机预兆 | 满编、强节奏 |
| rise 上升 | 建立动机与推进 | 6–8 | 第 1 小节动机陈述；中段应答；ostinato 分层进入 | 一直同力度 |
| climax 高潮 | 释放 | 4–6 | 和弦化/加八度再现；铜管+定音鼓进入；峰值和弦 | 只加快 tempo |
| void 抽空 | 静止成为重音 | 2–5 | 至少 1 小节完全留白；其余小节只有 1 个声部 | 低频/混响尾巴仍在 |
| tail 余韵 | 回落 | 4–9 | 增值动机或只剩钟声；衰减到 <20% | 直接回到开场强度 |

段落之间：
- 新段落第一小节重复上一段最后一个和弦（枢轴）；
- 或整段保持 pedal point，直到释放点；
- 不允许「上一段最后一个和弦」与「下一段第一个和弦」既无共同音也无 pedal 连接。

## 2. 逐小节动态曲线

设段落基准 `B`（0–1），段落内进度 `t = bar / (bars-1)`：

| 段落 | 曲线 | 说明 |
| --- | --- | --- |
| bed | `B × (0.55 + 0.45t)` | 慢起，让人先听到空间 |
| rise | `B × (0.78 + 0.52t)` | 持续渐强，结尾最高 |
| climax | `B × (0.90 + 0.16 sin(πt)) ± 0.02` | 中间略高，两端稍收；允许微小抖动 |
| void | `B × max(0.06, 0.95(1-t))` | 快速抽空 |
| tail | `B × (0.78 - 0.56t)` | 缓慢衰减 |

结果必须满足：
- `max - min ≥ 0.3`；
- 高潮峰值 > 铺垫峰值 + 0.25；
- 至少有 1 个 `silence` 小节（`dynamic ≈ 0.02` 且不调度任何声部）。

响度的每一次明显变化，必须同时伴随：声部进出、滤波截止变化、混响发送变化中的至少两项。

## 3. 滤波与混响

| 段落 | 低通截止（基准 900 亮度） | 混响发送（相对档位基准） |
| --- | --- | --- |
| bed | 620 Hz | 0.90× |
| rise | 860 → 1180 Hz | 0.85× |
| climax | 1380 → 1900 Hz | 0.62×（更干，突出冲击） |
| void | 380 Hz | 1.15×（更湿，制造空） |
| tail | 680 Hz | 1.00× |

延迟只发送给动机声部（0.05–0.10），不要整条总线都加延迟。

## 4. 配器进入时机

| 声部 | 首次进入 | 高潮 | 离场 |
| --- | --- | --- | --- |
| 持续低音 / drone | bed 第 1 小节 | 增益略升 | void 几乎关闭 |
| pad / 管风琴 | bed 第 1 小节 | 可换为 strings | tail 保留 |
| 低音 | bed 第 1–2 小节 | 加八度或脉冲 | void 停止 |
| 弦乐 | rise 中段 | 主导和弦与动机 | tail 减弱 |
| ostinato 第一层 | rise 中段 | 第二/三层进入 | void 全部停止 |
| 定音鼓 | rise 后段 | 心跳/锤击加密 | tail 第 1–2 小节后停止 |
| 铜管 | climax 后半 | 只在高潮出现 | void 前退出 |
| 钟声 | bed 稀疏 | 高潮少量 | void/tail 作为「第一声」 |
| 噪声/吸气 | rise 末尾 | 高潮冲击点 | 立即停止 |

原则：**没有一件乐器从头到尾一直在响**。每个声部都要有明确的进入和退场。

## 5. Ostinato 分层与节奏卡农

- 基础单元：3 个音，8 分音符（紧迫可用 16 分音符），强弱 pattern 例如
  `[1,0,1,1,0,1,0,1]`。
- 层数：bed 0–1；rise 1→2；climax 3；tail 1；void 0。
- 卡农错位：layer 0 偏移 0；layer 1 偏移 2 步 + 高八度；layer 2 偏移 5 步 + 低八度。
- 力度：layer 0 = 100%，layer 1 = 72%，layer 2 = 55%；每 4 步一个重音。
- 音区必须分开（低/中/高），否则三层同音区只会变成更吵的单层。

## 6. 打击乐语法

- **定音鼓心跳**：两下（0、1.5 拍）用于恐惧；高潮加速为（0、0.7、1.4、2.1）；
  音高放在低音区（MIDI 28–40），每下都有 pitch drop（+2 → 0 半音）。
- **低频轰鸣**：持续正弦（低音下方 12–24 半音）+ 低通噪声，只在 bed/rise 常态存在。
- **噪声重音**：高潮中点或段落切换，0.2–0.3 秒，带通滤波，不要盖过动机。
- **不要**：每拍都砸鼓、所有打击乐同一下、用高频噪声当「恐怖」。

## 7. 音色对比与声部密度

- 和弦声部在三段内应换色：bed 用 pad/管风琴，rise 用弦乐，climax 用弦乐+铜管，tail 用 pad/合唱。
- 同时发声的「旋律性声部」最多 1 个（动机）；其余是支撑（pad/bass/ostinato）。
- 高潮密度 0.65–0.85，不等于「所有声部都开」；留 1–2 个声部作为下一段的对比储备。
- 高潮反而要**降低混响**（0.62×），让冲击更干、更疼；留白段再拉高混响。

## 8. 与其他系统共存

- 配乐不得阻塞叙事：调度全部异步，单次调度上限 8 小节，后台标签页跳过节流补发。
- 与 BGM 共存时，由 BGM 侧 ducking 降低自身音量，配乐不主动压 BGM。
- 移动端/低性能设备：降到 `quality=1`（少振荡器、无延迟）或 `quality=2`（正弦骨架、无钟声/噪声）。
- `prefers-reduced-motion` 只影响 UI 动效，不改变音频结构与调度。

## 9. 验收清单

- [ ] 五段齐全，段落顺序固定；
- [ ] 每条 cue 的 `max(dynamic)-min(dynamic) ≥ 0.3`，高潮 > 铺垫 + 0.25；
- [ ] 至少 1 个 silence 小节；
- [ ] 至少 3 次动机陈述，且至少 2 种不同变形；
- [ ] 同一档位内至少轮换 2 族动机；
- [ ] 高潮有铜管/定音鼓（若档位允许）且不在开场出现；
- [ ] 和弦变化 ≥ 3 个不同根音；
- [ ] 同种子输出逐字节一致，换种子输出不同。
