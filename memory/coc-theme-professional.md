## 设计目标（彻底重做）

不参考现有主题 → 从零创建专业级克苏鲁美学 UI

### 核心方向
1. **视觉冲击力** - 看到就是克苏鲁恐怖的第一感受
2. **可读性** - 美学与易用性的完美平衡
3. **业界标准** - 参考 Darkest Dungeon、Sunless Sea、AABB Games 的专业设计
4. **真实资源** - 实际图片/字体，不是 CSS 模拟

## 主题层次结构

### L1: 基础配色系统
- 主色板（5-7 个颜色）
- 文本清晰度等级
- 对比度要求（WCAG AA）

### L2: 背景与纹理
- 环境背景（高分辨率图像）
- 可叠加的纹理层
- SVG 装饰元素（羊皮纸边界、古老符号等）

### L3: 组件特效
- 按钮（浮雕/内凹/发光）
- 卡片（羊皮纸/墨水/铁血效果）
- 聊天气泡（笔迹/纹理）
- 骰桌（古老祭坛风格）

### L4: 动画与交互
- 悬停反应（不是扫光，是"发现端倪"的视觉反馈）
- 加载动画（旋转仪式符号）
- 消息到达（诡异的"低语"视觉）

### L5: 国际化与无障碍
- 中英文排版优化
- 减少动画模式支持
- 高对比度备选方案
