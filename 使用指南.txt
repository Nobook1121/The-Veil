帷幕（The Veil）自托管使用指南
================================

这份说明写给第一次自己架设的人，请仔细阅读后自行进行部署。


一、这是个什么东西？
----------------------
帷幕是一个「AI 当守秘人（KP）」的线上跑团工具。

你需要做的只有两件事：
  1. 在自己电脑上把它启动起来；
  2. 把程序给出的网址发给朋友，朋友用浏览器打开就能玩。

不需要买服务器，不需要域名，也不需要证书。
只要电脑能开机、能上网（用来调 AI），就能用。


二、先准备好这几样
------------------
  · 一台 Windows 10 / 11 电脑（macOS 和 Linux 也能用，见第五节）
  · 能上网的网络
  · 一个大模型平台的 API Key，例如 DeepSeek、OpenAI、阿里云百炼等
    （没有的话，先去对应平台注册并充值少量金额，通常几块钱就够试玩）
  · 浏览器：Edge、Chrome、Firefox 都可以

可选项：Python3.11及以上（若无则会自动安装）


三、第一次启动（Windows）
-------------------------
1. 下载发布包
   到官网提供的发布页面选择合适的下载方式下载发布包。

2. 解压
   右键压缩包 →「全部解压缩」，解压到一个你自己找得到的文件夹。
   建议路径里不要有中文和空格，例如：
     D:\TheVeil

3. 双击启动
   打开解压后的文件夹，双击里面的 start.cmd。

   启动后会显示黑色的控制台，请等待他自行安装环境：
     · 若无 Python，则会自动安装（建议提前自行安装）；
     · 会创建一个独立的运行环境（.venv 文件夹）；
     · 会下载运行需要的组件。
   请耐心等待至控制台提示服务启动并且看到类似"listening on:127.0.0.1:8086"。
   请勿关闭窗口，关了服务就停了。

4. 打开网页
   等窗口里出现类似下面这一行：
     listening on http://127.0.0.1:8086
   打开浏览器，访问：
     http://127.0.0.1:8086

   如果 8086 端口被别的程序占用，程序会自动换一个附近的端口，
   以窗口里实际打印出来的地址为准。


四、第一次打开后的设置向导
--------------------------
如果网站还没有管理员账号，页面会自动弹出向导，按提示走完即可：

  第 1 步：配置 AI
    选择一个平台，填入 API Key 和模型名称，点「测试连接」。
    提示成功后保存。

  第 2 步：准备 Embedding 模型
    用来让 AI 更好地检索剧本和规则书。
    可以直接点「跳过」，以后再配置。

  第 3 步：给网站起名字
    这个名字会显示在页面标题和左侧栏。

  第 4 步：绑定域名（可跳过）
    只是展示用，暂时没有功能。

  第 5 步：可选功能（默认全部关闭）
    实时程序化配乐、实时配图、AI 对话语音默认都不勾选，
    避免刚部署就产生外部调用或额外费用；以后可在「设置 → 实时沉浸」中开启。

  第 6 步：创建 Owner 账号
    Owner 是最高权限账号，用来管理整个网站。
    请记住用户名和密码。若忘记后续可以通过命令找回，请自行翻阅wiki。

  第 7 步：进入系统
    点一下就会自动登录。

向导只会出现一次。
五、macOS 和 Linux 怎么启动（未验证，可能有严重bug）
---------------------------
  · 先安装 Python 3.11 或更高版本（官网 python.org 下载）。
  · 把发布包解压。
  · 打开终端，进入解压后的文件夹，先安装依赖：
      python3 -m pip install -r requirements.txt
  · 再运行：
      python3 server.py
  · 然后在浏览器打开 http://127.0.0.1:8086

没有 start.cmd 的一键安装，所以需要自己执行上面两条命令；
依赖只需安装一次，以后直接运行 python3 server.py 即可。


六、让朋友进来一起玩
--------------------
情况一：朋友和你在同一个 Wi-Fi（局域网）
  启动窗口里会打印一个「局域网地址」，形如：
     http://192.168.1.23:8086
  把这个地址发给朋友，他们用浏览器打开就能进。
  如果朋友打不开，多半是 Windows 防火墙拦住了这个端口，
  在防火墙提示里选择「允许访问」即可。

情况二：朋友在外地（异地联机）
  程序本身不负责把服务暴露到公网。常见做法有两种：
   1.使用用内网穿透工具（如 例如sakurafrp 等），
      以本机的8086端口创建一个tcp（或者https）隧道，将工具给你的公网地址发送给好友以链接；
   2.使用异地组网工具（如radmin，zerotier）
      使用你的工具创建一个虚拟局域网，并让好友加入。找到工具分配给你的地址（ps：radmin的在界面的开关的右侧），将地址后面加上端口号(例如"123.123.1.1:8086"，一般该地址会在控制台的其中一个"listening on"中展示）
   3. 使用云服务，此处教程省略。
  注意：请勿将服务端口直接暴露在公网上，也不要关闭登录验证。


七、怎么开始一局
----------------
  1. 进入「剧本」页，创建或导入一个剧本（也可以先用自带的示例）。
  2. 进入「房间」页，创建房间，记下房间码。
  3. 把房间码告诉朋友，他们注册/登录后输入房间码加入。
  4. 在聊天框里说话，用 @KP +要说的话 呼叫 AI 守秘人。

房间里的聊天记录会自动保存在本机，关掉程序也不会丢。
房主还可以手动「打存档节点」，方便以后回到某个剧情点。


八、如何更新
--------------------
  1. 先关闭程序窗口。
  2. 备份 data 文件夹。
  3. 下载新版本压缩包，解压到一个新文件夹。
  4. 把旧文件夹里的 data 整个复制到新文件夹里。
  5. 双击新文件夹里的 start.cmd 启动。
  6. 确认一切正常后，再删除旧文件夹。

不要直接用新版本覆盖旧文件夹，否则容易把旧的 data 一起覆盖掉。


九、常见问题
--------------
问：双击 start.cmd 后窗口一闪就没了？
答：多数是 Python 安装失败或网络下载依赖失败。
    重新双击一次；仍然失败的话，检查网络，或按窗口里的英文提示处理。

问：浏览器打不开 127.0.0.1:8086？
答：看启动窗口里实际打印的地址和端口，以它为准。
    也确认黑窗口还开着，没有被关掉。

问：朋友连不上我的局域网地址？
答：1）确认大家连的是同一个 Wi-Fi；
    2）在 Windows 防火墙里允许该程序访问；
    3）确认朋友输入的是完整地址，包括 http:// 和端口号。

问：AI 一直不回复或只回一半？
答：打开「设置 → 模型设置」，把「AI 请求超时」调大一些；
    同时检查 API Key 是否有效、账户余额是否充足。

问：房间右上角的 token 和花费是怎么算的？
答：每次 AI 调用后自动累加。花费需要先在
    「设置 → 模型设置 → AI 平台」里给模型填写输入/输出单价
    （单位是「每百万 token」）并选择币种，没填单价时就只显示 token。
    只有房主和房间管理员能看到这行小字。

问：忘记管理员密码了？
答：在程序窗口里（不是网页）输入下面这行并回车：
      user reset-password 用户名
    程序会打印一个临时密码，用它登录后会要求你设置新密码。
    如果连用户名也忘了，可以输入：
      user list
    查看所有账号。

问：想让朋友也有管理权限？
答：在程序窗口里输入：
      user promote 用户名 ADMIN
    改成 Owner 就把 ADMIN 换成 OWNER。请谨慎授予 Owner。

问：程序窗口里可以输入哪些命令？
答：输入 help 回车即可查看全部命令和中文说明。

问：能不能不用端口 8086？
答：可以。双击 start.cmd 无法直接带参数时，在文件夹空白处
    「Shift + 右键 → 在此处打开 PowerShell 窗口」，运行：
      .\start.cmd 8090
    然后访问 http://127.0.0.1:8090。


十二、安全提醒（请务必看）
--------------------------
  · data\config\ 里有 API Key，不要把这个文件夹发给别人，也不要上传到公开网盘。
  · 不要把服务端口直接映射到公网而不加任何保护。
  · Owner 权限可以管理整站，只给你完全信任的人。
  · 定期备份 data 文件夹，尤其是长期跑团的房间记录。
  · 如果怀疑密钥泄露，去模型平台后台作废旧 Key，再在设置里填新的。
