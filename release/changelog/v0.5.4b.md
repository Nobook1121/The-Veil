## 世界树 / 图谱 P8：图谱拖拽、连线与布局编辑

变更时间：2026-10-26 13:56

- 后端新增 `POST /api/scenarios/<id>/narrative/edges` 与 `DELETE .../edges/<edge_id>`：创建边校验两端节点存在、禁止自连、按 `from/to/type` 去重，删除支持 JSON 或查询串传 `base_revision`；两者都走既有乐观锁与 `narrative.save` 日志。
- 图谱页新增选择 / 连线 / 平移三种模式：选择模式可拖拽节点，松手后通过 `PATCH .../nodes/<node_id>` 写回 `layout.x/y`；连线模式依次点击起点与终点创建边，可在工具栏选择边类型与 hard/soft；平移模式拖动画布、滚轮以指针为中心缩放，另有「适配视图」。
- 点击边可选中并显示操作条，支持 hard/soft 切换与删除；节点详情新增「锁定布局」开关（写入 `layout_locked`），锁定后不可拖拽；「自动布局」按父子层级重排未锁定节点并通过一次 `PUT` 保存。
