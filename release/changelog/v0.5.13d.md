# v0.5.13d · 3B 房间级缓存 + NPC 头像 + 跨房间复用

时间：2026-11-03 13:32

## 结论

- 同一房间内场景/地点来回切换、同一 NPC 再次出场时直接复用已生成的图，不再重复调用生图平台、不再重复扣预算。
- 房间缓存真正落在 `data/rooms/<room>/immersive_cache/`，随房间归档保留；运行期只做临时副本用于访问 URL。
- 剧本作者新增「接受房间配图进入跨房间复用池」开关，默认关闭。关闭时其他房间严格不能读取该房间生成的图；开启且站点允许「写入剧本」后，其他房间跑同一剧本可跨房间命中，日志记录来源房间与命中层级。
- NPC 头像默认仍关闭（`illustration_npc_enabled = false`）；站点开启后才会为 KP 识别出的出场 NPC 生成 768×768 头像，并与场景图分 key 存放。

## 缓存 key

房间缓存与剧本缓存统一为：

`hash(场景/NPC 指纹 | 平台 | 模型 | 尺寸 | 画幅类别)`

- 场景指纹来自场景名与回合上下文；NPC 指纹为 `npc:<名称>`，因此同一 NPC 在房间内稳定复用同一张头像。
- 画幅类别 `scene` / `portrait` 进入 key，场景图与同尺寸 NPC 图不会互相串图。
- 命中时还会校验指纹、平台、模型、尺寸、类别五项元数据，不一致按未命中处理。

## 容量与驱逐

站点配置（`[immersive]`）：

- `illustration_room_cache_max_entries = 40`：单房间最多条目数，0 不限。
- `illustration_room_cache_quota_mb = 64`：单房间容量上限，0 不限。
- `illustration_room_cache_max_image_mb = 8`：单图上限，超限直接拒绝写入。
- `illustration_room_cache_overflow = "lru"`：超限策略，`lru` 驱逐最久未命中，`reject` 拒绝新图。

默认采用 LRU：配图属于可重建资产，驱逐旧图比拒绝新图更符合叙事连续性；对容量敏感的场景可切 `reject`。

## 安全校验

- 房间目录 `resolve()` 后必须落在 `room_dir` 内；缓存目录固定 `immersive_cache/`。
- key 只允许 24–64 位十六进制摘要，文件名后缀白名单 `svg/png/jpg/jpeg/webp`。
- 写入使用临时文件 + 原子替换；索引原子写入。
- 读取命中后复制到运行期目录时，运行期文件名用「房间 ID + key」再哈希，避免不同房间同 key 覆盖。
- 跨房间读取必须同时满足：剧本作者 `accept_room_images = true` 且站点 `scenario_record = true`；否则只写/只读本房间目录。

## NPC 图像

- `illustration_npc_enabled` 仍默认关闭，由站点 `immersive illustration npc on|off` 或管理端设置开启。
- KP 返回 `npcs` 数组后逐个生成头像；识别为空或失败静默跳过，不影响场景图与叙事。
- 头像尺寸默认 768×768，提示词与构图由 KP 的 `npcs[].prompt` 提供；同名 NPC 每房间只保留最新一张。

## 运维与权限

- 结构化日志：`immersive_room_cache hit/write/cleared`、`immersive_scenario_cache reuse/blocked`，含房间、来源房间、key、类别、平台/模型/尺寸、耗时、命中层级（`room` / `scenario` / `cross-room`）、是否降级。
- 房间控制台：`immersive cache show|stats` 只读查看房间与剧本缓存；`immersive cache room show|clear`、`immersive cache prune`、`immersive cache clear` 只操作本房间目录，破坏性操作默认预演，`--yes` 执行。
- 站点控制台：沿用 `immersive scenario stats|prune|clear` 管理剧本缓存。
- 权限：房间控制台执行默认要求 `admin`；普通玩家只能查看沉浸状态与配图历史，不能清理缓存或触发高成本调用。

## 已知限制

- 旧版本房间缓存索引存在房间状态文件里、图片在运行期目录，本轮不自动迁移；首次重新生成后会写入新的房间目录缓存。
- 跨房间命中只按「同一剧本 + 相同指纹/平台/模型/尺寸/类别」判断，未做内容感知去重。
- 站点控制台暂不提供跨房间缓存汇总列表，房间级统计需进入对应房间控制台查看。
