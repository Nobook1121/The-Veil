# v1.0.5

## 前端库本地化、道具与插件加固、成长与团录收尾

改动时间：2026-11-12（Asia/Shanghai）

### 版本

- 应用版本统一为 **1.0.5**，唯一真源为 `backend/trpg_server/version.py` 的 `APP_VERSION`。
- 历史 changelog 不改写。

### 一、前端库本地化与渲染性能

- marked 15.0.12、DOMPurify 3.4.16、Socket.IO 4.7.5 与 KaTeX 0.16.11 全部移入 `data/assets/vendor/`，按 Bootstrap → Socket.IO → marked → DOMPurify → KaTeX 同步加载；离线与内网部署不再依赖外部 CDN。
- CSP 的 `script-src` 收敛为 `'self' 'unsafe-inline'`，移除已不需要的 CDN 白名单。
- 新增 `data/assets/vendor/VENDOR-MANIFEST.json`（含各库版本与 SHA-256），由 `tests/test_frontend_project_structure.py` 与 `scripts/package-release.ps1` 双重校验，防止发布包内被替换。
- 历史消息批量渲染改用 Set 去重（O(n) 取代 O(n²) DOM 查重），滚动收尾统一放到 `finally`，不再逐条强制重排。

### 二、启动脚本

- `start-bootstrap.ps1` 不再只看 `requirements.txt` 的 SHA-256：指纹不一致时先用 `importlib.metadata` 逐条核对已安装包，满足则只刷新指纹并跳过安装，不满足才打印缺口。
- 依赖检查不再静默执行 pip 自升级，避免启动窗口看起来像卡死。

### 三、道具工坊加固

- 脱敏（`burn` / `ink`）改为真实遮盖：先合并重叠与相邻区间，PDF 后处理按文字 bbox 绘制涂黑矩形或烧灼焦边，两种模式视觉不同；混排字宽不再偏移。
- 道具查看器新增「问问 KP」，聊天请求携带 `prop_id`；后端只注入该玩家可见内容并禁止复述遮挡部分，回复只做一次性展示，不落库、不广播。
- `props.create` / `props.reveal` / `props.update` 三个 Agent 工具仅 KP 可调用；请求体角色越权时记录警告并回落默认角色，避免玩家聊天被直接 403 打断。
- 消息可见性过滤下沉到 `room_ops/visibility.py`，房间详情、加入房间、成员绑定、回档节点、自动存档与团录导出统一复用，`partial` 道具卡不再从旁路泄露。
- 渲染安全：增加排队上限与等锁超时、定时 prune、临时文件原子替换；缓存键并入模板、字体签名以及照片与贴图的 mtime/size，强制重绘不会命中旧 PDF。
- 渲染熔断：单次渲染超过 5s 记录 WARNING；单次超过 30s 或连续 3 次失败时按房间冷却 30s，路由直接返回 `prop.render_circuit_open`（503），不再排队；熔断状态只存内存，进程重启即恢复。
- 房间锁改为引用计数 + 重入锁，淘汰只清理空闲条目；配额满且无空闲条目时短暂等待持有者退出，不再强行淘汰导致同房间双锁。

### 四、第三方插件

- `GET /api/plugins` 每条新增 `source`（`plugin_dir` / 预留 `template_pack`），设置页直接读取来源，不再按 `has_code` 推断，缺失时显示「未知来源」。
- `enabled.json` 损坏时按空列表降级并告警；`/api/plugins/rescan` 的异常统一映射为稳定的 500。
- 插件 id 禁止占用核心 Agent 工具命名空间，激活时再次与核心工具表比对，冲突即拒绝。
- 禁用代码插件时回收不再启用的模块并从 `sys.modules` 清除，同时把「需重启」持久化到条目，设置页刷新后仍展示。
- 设置页新增「插件」分类，可查看清单、来源、能力、启用/禁用与回滚提示。

### 五、团录导出

- `job.json` 随导出目录落盘，内存未命中时从磁盘恢复；`queued` / `running` 任务在重启后转为 `failed` 并给出 `trace_id`。
- 新增 300s 看门狗超时；`keep_exports_days` 在启动与创建导出时清理过期目录。
- `DELETE` 先鉴权再判断状态，区分 404 / 403 / 409；前端仅发起人、房主 / 房管 / 站点管理员显示入口。

### 六、CoC7 成长与战斗

- 新增 `training.py` 与可选房规 `coc7_growth_training`；成长标记写入 `extensions.growth.marks` 并兼容旧位置，schema 预声明 9 个命名空间与版本。
- 新增 `check.combined` / `check.group`、`character.spend` / `character.contacts` / `character.train`、`san.treat`、`combat.knockout` / `combat.hit_location`、`rule growth|train|san treat|combat` 与 `status` 新字段。
- 奖励 / 惩罚骰统一按净额夹在 ±2；射击体格差改为「目标减攻击者」。
- 毒剂到期结算：战斗轮推进到登记轮次时自动结算，战斗外可用 `combat.poison_queue` 按回合或游戏时间（`onset_days` / `onset_hours`）登记。
- 自然恢复与典籍阅读在省略天数 / 周数时，若开启游戏时钟 `coc7_game_clock` 则读取游戏时间差，不自动推进时间。
- 疯狂发作区分即时（`1D10` 轮）与总结（`1D10` 小时），即时症状由 `coc7_sanity_bout_safety_minutes` 兜底收尾；习惯恐惧按单次遭遇最大损失设上限；现实认知改用当前 SAN 检定。

### 七、设置与关于

- 关于页重写：新增检查中状态与 40 次轮询上限、复制仓库地址、更新说明、赞助面板、隐私与 CoC 声明；`play` / `model` / `knowledge` / `system` / `immersive` 小节与折叠卡补齐，中英各补 45 个文案键。
- `credits.json` 换成 12 条真实依赖并补 `schema_version` / `updated_at`；`[update] channel` 改为枚举，`request_timeout_seconds` 限制 3–30。
- 「特别鸣谢」新增 Bilibili 用户 399626（提供「拾页Ⅱ」跑团道具模板库）：名称可点击、新窗口打开并带 `rel="noopener noreferrer"`，说明文字收进 ⓘ 按钮，中英文案齐全。
