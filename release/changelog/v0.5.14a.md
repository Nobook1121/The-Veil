# v0.5.14a（2026-11-03 19:45）

## AI 对话语音配音（P1）

- **台词标记协议**：`config/templates/roles/kp.md` 新增 `【NPC:名字】` 与 `【旁白】` 约定；服务端解析后剥离标记再持久化正文，`message.metadata.voice_segments` 保留分段，历史与上下文回灌模型时不再带标记。
- **9 个内置人设音色**：8 个 NPC（男/女 × 少年/青年/中年/老年）+ 1 个旁白，各自有独立 pitch、rate 与偏好系统音色关键词；同一 NPC 按房间映射 > 剧本自动分配（性别/年龄关键词 + 名字哈希）> 人设默认稳定命中，不会每回合换声。
- **前端系统引擎播放器**：新增 `frontend/src/app/immersive/voice.ts`，单一播放队列、同时只播一条；Web Speech 异步加载音色，优先 zh-CN，匹配失败记录降级原因；首次用户手势前只准备不播放并显示「点击开启语音」；聊天消息旁提供小喇叭按钮，可单条重播。
- **语音/音乐总线分离**：语音播放期间通过 `TrpgBgm.setDuck(true)` 与新增的 `TrpgImmersiveMusic.setDucking(level)` 压低 BGM 与实时配乐，结束后 400ms 恢复，攻击 80ms；语音不接入音乐引擎的音频图。
- **分层设置**：站点级 `general.toml [immersive]` 的 `voice_*` 配置、房间 `voice.json` 与房规收紧、个人 `trpg_immersive_personal` 覆盖；语音默认关闭、自动播放默认关闭。
- **引擎适配层**：统一 `synthesize(segment, profile)`；本阶段只实现 `system`，`local`/`cloud` 明确返回 `engine_unavailable` 或 `engine_not_allowed`，不发起外部请求。
- **日志与控制台**：新增 `voice_*` 结构化事件族；站点 `voice status/on/off/engine/engine allowed/profile list/map list|set/test/usage`，房间 `voice status/on/off/map set/mute/usage`；高成本或破坏性操作默认预演，`--yes` 执行。
- **文档**：同步 `docs/console-commands.md` 与 `docs/the-veil.wiki/实时沉浸系统.md`。
- **测试**：新增 `tests/test_voice_markup.py`，覆盖标记边界、正文剥离、metadata 契约、启发式与别名、profile 稳定、房间收紧、个人覆盖、控制台 dry-run、引擎降级与 HTTP 401/403。

## 限制与后续

- 本阶段不实现语音缓存、本地模型与云端调用；`local`/`cloud` 仅保留适配入口。
- 云平台 Base URL / 模型 / 密钥已进入站点配置并掩码展示，管理界面暂不提供密钥写入控件。
- 浏览器实际可用音色取决于操作系统；中文音色缺失时会回退到默认音色并记录 `no_zh_voice`，不静默失败。
