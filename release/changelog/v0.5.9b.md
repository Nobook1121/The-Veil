# v0.5.9b（2026-11-03 00:02）

## 实时沉浸右侧栏与配图

- **收起/展开动画重做**：右侧栏宽度改为 300ms `cubic-bezier(0.22, 1, 0.36, 1)` 过渡；内容使用固定展开宽度 + opacity + 12px 位移淡出，避免收起过程中文字反复换行；窄轨延迟淡入。`prefers-reduced-motion` 下直接切换。
- **底部独立分区**：场景画面与配乐从「浮在成员栏里的小卡片」改为右侧栏底部独立区块，带「SCENE / 场景」标题栏与「配乐 · 档位/强度」摘要，独立顶部分隔线与半透明背景；成员列表优先占据剩余高度并滚动，底区最高 `min(52%, 360px)`，只滚动自身。
- **灯箱与下载**：点击主画面或历史缩略图进入灯箱，支持 Esc / 点击遮罩关闭，锁住底层滚动并在关闭后恢复焦点，Tab 焦点循环限定在灯箱内；窄屏适配 `96vw / 72dvh`。新增下载按钮，文件名包含剧本、房间与时间；外部 URL 仅允许下载本房间历史中出现过的图片，由后端代理取回，失败明确提示。
- **剧本配图缓存（可配置）**：新增 `illustration_scenario_record`（默认 `false`）与 `illustration_scenario_prefer`（默认 `true`），站点设置与房规三态收紧均可用；key 为「剧本 ID + 场景指纹 + 平台 + 模型 + 尺寸」，命中后直接复用、不重复调用、不计预算；写入剧本 `immersive/` 目录并保存生成时间/平台/模型/尺寸/场景指纹/宽高元数据。
- **容量治理**：单剧本配额默认 256MB（0=不限）、单图上限默认 8MB，超限策略默认 `lru`、可选 `reject`；安全路径与文件名白名单防目录穿越；旧数据无指纹直接跳过，不误命中；命中/未命中、写入结果、复用来源、容量拒绝与 LRU 驱逐均写入日志。
- **控制台**：新增 `immersive scenario record|prefer|quota|max-image|overflow|stats|clear|prune`（默认 dry-run，`--yes` 执行）；房间侧新增 `immersive cache show|clear|prune` 与 `immersive cache record|prefer <on|off|inherit>`，只能收紧。
- **文档**：同步 `docs/console-commands.md`、`docs/the-veil.wiki/实时沉浸系统.md` 与 `docs/project-map.md`。

## 兼容、限制与迁移

- 不新增第三方依赖，`THIRD-PARTY-LICENSES.md` 无变更。
- 剧本图片会进入剧本目录备份/迁移；房间归档仍只包含会话 JSON，不打包图片。
- 外部失败回落的程序化图不写入剧本缓存，避免把降级结果固化为默认画面。
