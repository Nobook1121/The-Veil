# v1.0.1

## 修复赛博档案与秘典主题下房间弹窗无法点击

改动时间：2026-11-06 23:50（Asia/Shanghai）

### 版本

- 目标版本 **1.0.1**。

### 主题与浮层

- 赛博档案主题（PR #7）：移除 `body.theme-cyber-2 .col-10` 的 `z-index: 1`。该值让 `.col-10` 形成层叠上下文，把弹窗的 `z-index: 1050` 关在其中，而挂在 body 上的 `.modal-backdrop`（`1049`）处在根层叠上下文，会在整片上盖住弹窗，导致「创建房间」「房间规则」点不到。去掉后 1050 可正常压过遮罩，与 `contract.ts` 中「主题不得在浮层祖先上建立层叠上下文」的约定一致。
- 秘典主题（同源修复）：`body.theme-tome` 增加 `isolation: isolate`，纸张底纹 `::before` 与环境光 `::after` 由 `z-index: 0` 分别降至 `-2` / `-1`，并移除 `body.theme-tome .col-10` 的 `z-index: 1`。底纹仍绘制在页面底色之上、正文内容之下，房间弹窗恢复可点击。
