# v1.0.0

## 正式发布：开箱即用发布包、E1b 提灯品牌定稿与首启引导补全

改动时间：2026-11-05 14:05（Asia/Shanghai）

### 版本

- 根包版本升至 **1.0.0**（`package.json`），后端新增 `backend/trpg_server/__init__.py` 的 `__version__ = "1.0.0"`。
- 发布包命名统一为 `the-veil-v1.0.0.zip`（前缀 `the-veil`，不使用 `aibasedtrpg`）。

### 品牌图标（E1b 暖光提灯定稿）

- 正式图标改用概念方案 **E1b**：
  - `icon.svg` ← E1b 主母版；
  - `icon-simple.svg` ← E1b 32px 独立重画版，并新增 32px 专用渲染档；
  - `icon-16.svg` ← E1b 16px 独立重画版；
  - `icon-mono.svg` ← E1b 单色版；
  - `icon-maskable.svg` ← 以 E1b 几何按 1.20 倍居中缩放，背景铺满画布，安全圆内最远点约 384 < 409.6。
- 通过 `scripts/export-brand-icons.py` 重出 `icon-512/256/128/64/48/32/16.png`、`icon-maskable-512.png`、`icon-mono-256.png`、`apple-touch-icon.png` 与 `favicon.ico`。
- 48px 改为由主母版渲染，32px 使用 32px 独立重画版；16/32 档尺寸、四角 alpha、ICO 条目已复验。
- `copyBrandAssets()` 增加排除规则：`concepts/` 与 `preview.html` 不进入 `dist/public/assets/brand/`，也不进入发布包。
- `gh-pages` 宣传站工作树中的品牌资源已同步为新图标（该 worktree 改动保持未提交）。

### 首次引导（setup）

- 向导由 6 步扩展为 7 步，新增第 5 步「可选功能」：实时程序化配乐、实时配图、AI 对话语音配音，三项默认关闭。
- 新增 `POST /api/setup/features`：仅接受布尔值，写入 `[immersive]` 的 `music_enabled` / `illustration_enabled` / `voice_enabled`，并加入 setup 阶段的 CSRF 豁免列表；创建 OWNER 后随引导一起锁定。
- `config/templates/general.toml` 中 `music_enabled` 默认值改为 `false`，保证跳过该步的新实例同样不会自动播放实时配乐。
- 完成页新增「查看部署与访问文档」入口（`/DEPLOYMENT.md`）。
- 可选功能保存失败时使用项目既有的通知组件提示，不引入浏览器原生 `alert/confirm/prompt`。

### 发布与文档

- 新增 `AGENT-INSTALL.md`：面向 AI Agent 的三段式（命令 / 期望输出 / 失败处理）安装手册，含机器可读 front matter、Windows 与 Linux/macOS 两套命令、引导 API 全流程、禁止项与验收清单。

- 更新 `README.md`、`使用指南.txt`（包内）中的向导步骤与文档入口。
- `.gitignore` 新增 `/.screenshots/` 与 `/.trae-html-share-packages/`，本地产物不入库。
- `release/changelog/` 全套不进入发布包。
