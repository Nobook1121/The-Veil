# v0.5.6b

发布日期：（待发布）

变更时间：2026-11-02 19:40

本次更新在 v0.5.5b 的实时沉浸系统上做两项增量改造：把生图服务商参数提升为独立的「生图模型平台」配置入口，并新增由大模型驱动的「AI 音乐导演」层。两者都沿用原有的分层配置、权限、审计、控制台与降级约定，任何外部调用失败都不会阻塞叙事或播放。

## 生图模型平台（管理员侧）

变更时间：2026-11-02 19:40

- 新增 `backend/trpg_server/immersive/image_platforms.py`：平台条目的增删改查、默认平台、密钥分离存储、内置预设、连接测试与旧配置迁移。
  - 公开配置写入 `config_dir/imageplatform/*.json`，API Key 写入 `RUNTIME_DIR/config/imageplatform/*.json`，二者分离。
  - 每条包含 `id`、名称、协议（`openai_images`）、Base URL、模型、尺寸、超时、启用状态与密钥掩码。
  - 内置 OpenAI、SiliconFlow、阿里云百炼、智谱与自定义预设；协议与尺寸做正则校验。
  - `probe_platform` 优先请求 `/v1/models` 返回可用模型，失败再做一次最小生成探测；Base URL 已含 `/v1` 时不重复拼接。
  - `migrate_legacy` 读取旧的 `illustration_provider/base_url/model/size/api_key`，生成一条平台条目并清空旧字段，只执行一次。
- 修改 `backend/trpg_server/immersive/illustration.py`：外部生图改为解析默认平台；`provider=platform` 且无可用平台时降级并记录 `platform_not_configured`。
- 修改 `backend/trpg_server/immersive/service.py`：每个配置目录只做一次旧配置迁移。
- 修改 `backend/trpg_server/routes/immersive.py`：新增平台列表/详情/保存/删除/设默认/密钥/测试/迁移接口；`GET /api/immersive/config` 管理员侧附带预设、协议与平台摘要；密钥只回掩码。
- 修改 `backend/trpg_server/immersive/audit.py`：平台与导演的管理操作统一写审计日志（操作者、动作、变更字段、结果），敏感字段脱敏。

## AI 音乐导演（大模型 + 规则回退）

变更时间：2026-11-02 19:40

- 新增 `backend/trpg_server/immersive/director_schema.py`：严格 schema 校验并白名单化乐谱（场景/情绪、调式、tempo、和弦走向、乐器编制、动机序列、段落推进、动态起伏）。
- 新增 `backend/trpg_server/immersive/director.py`：
  - 上下文指纹（叙事文本 + 场景/档位 + 当前音频状态）与 TTL 缓存（最多 200 条，`ttl=0` 不复用）。
  - 每日调用预算预留；按触发间隔（每 N 回合）决定是否调用。
  - 后台线程池执行，完成后回调；超时、异常、非法输出、低置信、超预算一律回退。
  - 缓存命中直接同步复用，不消耗预算。
- 修改 `backend/trpg_server/immersive/music.py`：`plan_music` 保留历史上下文；新增 `apply_director` 把导演乐谱合并回计划（档位、段落、动态与指纹）。
- 修改 `frontend/src/app/immersive/music-engine.ts`：按谱渲染——调式映射音阶、tempo 直接驱动速度、和弦映射走向、动机驱动旋律、段落驱动动态；乐谱不完整或越界时回退规则音色。
- 修改 `frontend/src/app/immersive/index.ts`、`frontend/src/types/immersive.d.ts`：计划与状态新增 `score` / `director`。
