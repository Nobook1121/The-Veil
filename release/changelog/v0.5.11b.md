## 独立「主题」标签卡

变更时间：2026-11-03 10:07

- 个人设置新增「主题」分区（`#profile-theme`）：主题卡片 + 跟随默认主题 + 详情参数；选中主题或调整参数立即预览，保存后才写入个人配置，取消会回退到已保存状态。
- 新增通用待保存提示条（`#profileThemePendingSaveBar` / `#profileThemePendingChangeCount`），与既有个人设置保存确认流程一致。

## 统一主题能力契约

变更时间：2026-11-03 10:07

- 新增 `frontend/src/app/themes/contract.ts`：定义 `ThemeDefinition`（id、bodyClass、labelKey、descriptionKey、preview、深浅两套 tokens、supportsLightAndDark、animated、reducedMotion、overlayPolicy、settings schema、mount/unmount/apply）。
- 浅色、深色、系统、赛博档案、深渊帷幕、秘典全部迁移到该契约；配色主题只接配色（`animated: false`），动画主题声明 `reducedMotion: "freeze"`。
- 设置面板由 `frontend/src/app/themes/settings-ui.ts` 按 schema 生成 `slider` / `color` / `select` / `toggle` 控件，每行提供「恢复默认」，个人面板显示「管理员锁定」。
- 层叠上下文约定写入契约：浮层宿主固定 `body`，主题不得在祖先元素上设置 transform / filter / backdrop-filter / perspective / contain / isolation / will-change / z-index。头像上拉窗、世界意志弹窗、配图灯箱、通知均遵循该约定。
- 新增 `tests/test_theme_contract.py`：校验必需字段、深浅 token、浮层策略、reduced-motion、滑杆默认值/范围/步进、legacy 迁移键、设置面板控件与脚本/样式加载顺序。

## 各主题可调项

变更时间：2026-11-03 10:07

- 浅色 / 深色 / 秘典：6 个 token 级颜色（页面背景、面板背景、主文字、次文字、强调色、边框），带对比度提示、恢复默认、非法值回退。
- 赛博档案：总开关、氛围强度、数据雨密度、数据雨速度、下落字符集五档预设（片假名 / 程序符号 / 十六进制 / 二进制 / 混合）、主色 / 背景色 / 文字色、指针锁定框。
- 深渊帷幕：聊天 / 左侧栏 / 右侧栏不透明度、遮罩透明度、背景模糊、拖尾开关 / 强度 / 密度、触手密度 / 高度 / 高度随机性 / 摆动速度、法阵大小、飘浮符文开关。旧面板的遮罩与模糊设置已并入同一面板。
- 所有滑杆均有默认值、范围、步进，越界值由 `coerceValue` 钳制；拖动预览使用 `requestAnimationFrame` 节流。

## 兼容与迁移

变更时间：2026-11-03 10:07

- 新存储键 `localStorage["trpg_theme_settings_v1"]`；首次加载迁移 `trpg_abyss_fx_settings` / `trpg_cyber_fx_settings`，只保留 schema 认识的显式键。
- 迁移前原值备份到 `trpg_theme_settings_legacy_backup`，随后删除旧键，避免两套设置并存。
- 回退策略：从备份键读回旧值即可恢复；删除新键则回落到字段默认值与站点默认。
- 新增配置 `config/schema.py` 的 `appearance.enabled_themes`（as_str_list）与 `appearance.theme_overrides`（as_text），并同步 `config/templates/general.toml`；站点级配置仅管理员可写，个人覆盖仅写本机。

## 已知限制

- 个人主题选择仍沿用既有的 `trpg_user_theme` cookie（浏览器端生效），参数覆盖走 `trpg_theme_settings_v1`；两者作用不同，未合并存储。
- 主题卡片缩略图是 CSS 色板预览，不是实时截图。
- 浅色 / 深色只提供配色项，不提供动画项；赛博与深渊的减少动态效果策略为直接停用动画（freeze）。
- 个人在主题面板里的即时预览只影响当前浏览器，刷新后按已保存值恢复。
