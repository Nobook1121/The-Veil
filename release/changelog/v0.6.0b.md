## 手写动效实现

- **Hero 入场**：段落分为 6 个错峰节点（0 / 180 / 560 / 760 / 910 / 1010 ms），用 CSS transition 做透明度与 10–20px 上浮，缓动统一为 `cubic-bezier(.22,1,.36,1)`，无回弹。
- **场景预览 / 能力卡 / 主题卡**：IntersectionObserver 在「元素顶部到达视口 84% / 86%」时触发一次，卡片按 80–100 ms 间隔错峰上浮；触发后断开观察，不随回滚重播。
- **插画 scrub**：滚动循环内按场景区在视口中的行程计算 1.02 → 1.12 的缩放，只在桌面端启用。
- **五段 cue**：以「面板顶部到 76% 视口 → 面板底部到 22% 视口」为区间计算进度，进度每跨过 1/5 点亮一段；已点亮状态只增不减。窄屏不做滚动计算，直接一次性点亮到终态。
- **阅读进度条**：与插画、cue 共用同一个 rAF 循环，按 `scrollY / (scrollHeight - innerHeight)` 写 `scaleX`，桌面端显示。
- **波形与法阵**：改为 CSS `@keyframes`，波形按 `nth-child` 变化时长与负延迟形成错落；法阵外环 70s、内环反向 48s。IntersectionObserver 在元素离开视口附近时把 `animation-play-state` 切到 paused。
- **读写与节流**：滚动监听为 passive，只置脏标记；一帧内统一读取 `scrollY` 并批量写样式，元素位置用 `offsetTop` 在 resize / load / 字体就绪时缓存，循环内不再触发布局计算。
- **降级**：`prefers-reduced-motion: reduce` 时不添加动效初始态、不注册滚动监听、不启动 rAF，进度条隐藏；不支持 IntersectionObserver 的极老浏览器退化为一次性几何判定。
