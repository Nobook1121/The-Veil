# v1.1.0

## 世界包导入、FVTT 风格战桌与安全效果引擎

改动时间：2026-11-23（Asia/Shanghai）

### 版本

- 应用版本统一为 **1.1.0**，唯一真源为 `backend/trpg_server/version.py` 的 `APP_VERSION`。
- 从 1.0.7 起累积的改动全部进入本版本；历史 changelog 不改写。
- 发布包内新增 `更新.cmd`：可在不丢失数据的前提下从 GitHub 更新到最新版本（见第九节）。

### 一、Foundry VTT 世界包导入

- **直接导入世界包**：支持把 Foundry VTT 的 world 包（zip）导入为剧本，自动读取场景、墙体、光源、棋子、角色/NPC、日志与素材；不需要额外转换工具，也不需要先装 Foundry。
- **场景直接还原**：场景底图、网格尺寸与偏移、墙体（墙/门/窗/地形）、光源（明暗半径、颜色、锥形角度）、棋子初始位置全部按世界包给定值落库；底图尺寸决定地图边界，不再出现「世界 50 格、底图只占中间一小块」的错位。
- **墙体与移动**：玩家与 AI 的移动都会被墙体阻挡；开门后可通过；落点压在墙上会被拒绝并回弹。拒绝提示对玩家隐藏具体墙号，避免在迷雾下逐格试探暗墙。
- **角色与 NPC**：角色转成 5e 角色卡（属性、HP、AC、法术位、熟练、装备、等级），NPC 转成剧本怪物模块；重导同一世界包是幂等升版，不会生成重复剧本。
- **IP 与素材**：素材以内容寻址方式落到剧本目录，封面按剧本记录直接展示；已删除（归档）的剧本不会被重导悄悄复活。

### 二、Battle Table（FVTT 风格战桌）

- **进入 5e 房间即切换**：房间主视图变成战桌：地图居中、左上工具栏、右侧图标栏、骰子直接落在地图上；左栏可自动收起。
- **工具与模板**：选择/移动、测距、圆形/锥形/直线/矩形范围模板；模板可拖动、右键删除，Esc 取消。
- **场景面板**：DM 可看到全部场景缩略图、棋子数与当前场景，一键切换；玩家只看到自己所在的场景，不会收到场景清单。
- **角色面板**：AC / 命中 / 法术豁免 DC / 被动察觉四盒速览 + HP 条 + 生命骰与法术位资源池；DM 额外看到 NPC/怪物分组。
- **骰桌**：检定、豁免、攻击统一落在地图上的 3D 骰；自然 20 / 自然 1 有提示；快捷键与骰子数量上限可调。
- **规则速查**：战桌左上「书」图标或 `/`、`Ctrl+K` 打开规则速查，支持法术/怪物/装备检索、机器翻译标记与来源深链。

### 三、D&D 5e 规则与角色卡

- **角色卡重构**：六页签（详情 / 物品 / 特性 / 法术 / 效果 / 传记）+ 左栏 AC / HP / 生命骰 / 死亡豁免 / 力竭；短休、长休、灵感、XP 与保存入口统一在卡面。
- **建卡向导**：概念 → 属性（27 点购点 / 4d6 去最低 / 标准数组）→ 技能与装备 → 预览建卡，服务端统一计算，避免前端算错。
- **升级向导**：确认等级 → HP（服务端掷骰或取平均）→ 职业特性 / 子职 / 属性提升 → 法术与预览；子职候选同时提供 SRD 与扩展库（法师 2 级有 20+ 个可选项）。
- **物品页签**：每件物品可展开查看完整 FVTT 物品文档（类型、伤害、射程、护甲、使用次数、物品活动、效果与模块字段），只读展示，编辑仍走扁平字段。
- **休息**：短休消耗生命骰回血，长休恢复生命、生命骰与法术位、力竭降级并结束专注。

### 四、效果引擎（Active Effects）

- **完整 FVTT 路径镜像**：以 FVTT 角色数据模型为镜像，按路径结算效果；支持 0–5 六种模式、列表增减、物品作用域效果与按类型/装备状态激活。
- **三档如实分级**：真正进入数值的路径标「已生效」；已记录但当前没有消费方的路径标「已记录·暂未生效」；连镜像模型都没有的路径单独计数。导入报告与角色卡效果页签分组展示，绝不把「没做的事」标成生效。
- **已接入的数值**：AC、先攻、攻击/伤害、豁免、技能、被动察觉、法术 DC 与攻击、抗性/易伤/免疫/条件免疫、速度（含步行/飞行/游泳/攀爬/掘进/跳跃分速）、生命上限与当前生命、语言、减伤、属性值合并、熟练加值、物品改名、物品活动（攻击加值/属性/伤害骰/射程）、目标侧优势/劣势（如 Faerie Fire、Protection from Evil）、半身人幸运重掷、暴击阈值。
- **安全公式求值**：支持 `@abilities.dex.mod`、`NdM`、四则运算与白名单函数的安全求值（AST 白名单，不执行任意脚本）；确定性公式在派生时结算，含骰公式留到使用时掷。
- **工作流钩子（安全等价物）**：把模块宏分诊成声明式 DSL（触发点 + 条件 + 白名单动作），可安全执行加骰伤害、条件、治疗、临时生命与资源消耗；无法安全等价的宏保留原文并标记「需人工确认」，服务端不执行第三方世界包里的 JavaScript。
- **物品文档保真**：装备行保留完整物品文档，引擎优先从文档读取；旧角色卡没有文档时行为不变。

### 五、AI DM 与内容

- **AI DM 战桌工具**：放置范围模板、切换场景、全房掷骰广播、检索世界树；每回合自动注入「战桌状态」一行（当前场景、棋子数、战斗回合、模板数）。
- **世界树与知识库**：世界包日志自动切成场景文本与叙事图谱，AI 可按关键词检索节点与关系；导入默认走确定性切块，可选开启 AI 语义增强。
- **5e 内容库**：随包提供 SRD 内容；另支持本地 5e 中文资料库（法术/怪物/装备/子职/专长/背景），供 AI 检索与卡面使用，资料库不进仓库、按许可声明单独存放。

### 六、地图与光照

- **光照重做**：多光源合成、颜色与明暗分层、墙体遮挡投影、锥形光与棋子自带光源（拖动即时跟随）；暗视只对有暗视数据的角色生效。
- **迷雾**：按观察者分别记录探索；未探索/探索记忆/可见三档；逐格增量揭示，移动时不再整屏闪烁；底图外的区域与未探索同色。
- **性能**：40 光源 + 200 面墙、1600×900 视口下，常规帧约 5–8 ms；只有全部光源同时移动的极端帧略超预算。

### 七、稳定性修复

- **修复进入 5e 房间后地图空白**：空底图场景会在 `drawStage()` 与 `loadBackground("")` 之间无限递归（栈溢出），导致画布与地图插件都无法挂载；现在只在原本有底图时重绘一次。
- **修复导入世界包后剧本列表要等一会才出现**：剧本列表有 60 秒缓存，导入器直接写盘时没有失效缓存；现在任何剧本写入/删除都会立即刷新列表缓存。

- 修复房间卡封面破图（绝对 URL 被二次拼接、空封面渲染破图）。
- 修复导入后新剧本不出现在剧本列表（归档记录被幂等匹配）。
- 修复旧房间地图边界不随重导更新：装配标记升级后，进房会自动按新口径重刷场景（只动地图数据，不重复并入 NPC）。
- 修复切场景时旧底图残留/黑帧（代际守卫 + 新图就绪再替换）。
- 修复效果引擎惰性加载把「第一次没找到」永久缓存、导致三档计数被打回 0 的问题。
- 修复战斗「困在同一个回合」（裸工具调用被当正文、回复缓存命中假动作）。
- 修复 CoC7 闪避基础值（应为 DEX/2）与理智初始值未夹到神话上限。

### 八、发布包内容

- 随包官方插件：`dnd5e-srd`、`dnd5e`、`dnd5e-vtt`、`veil-map`、`fvtt-world-import`，默认启用。
- 随包示例剧本「裂隙回廊（示例剧本）」；本机测试剧本、用户数据、运行数据、开发文档、研究与测试代码都不进发布包。
- 首次启动进入安装向导：设置站点名称、管理员账号与基础配置；配置模板中 `setup_dismissed = false`，打包时会校验，防止出现「解压后跳过向导」的坏包。

### 九、应用内一键更新

- 「设置 → 关于」的更新区新增**立即更新并重启**：OWNER 点一下即可完成「下载 → SHA-256 校验 → 解压暂存 → 替换程序文件 → 重启服务」，不再需要手动解压覆盖。
- **新版本自动提示**：OWNER 打开应用后会自动检查 GitHub（6 小时节流），发现新版本弹出提示，可选择「立即更新」「稍后」或「忽略此版本」；忽略只记住当前版本号，下个版本仍会提示。
- 替换只覆盖程序文件，`data/`（剧本、账号、聊天记录、插件数据）、`.venv/`、`_backup/` 一律保留；更新前会把 `data/` 备份到 `_backup/<旧版本>-<时间>/`。
- 若替换助手意外失败，下次启动会先应用暂存的更新再加载程序（pending 兜底）。
- 只有当服务已下载并校验完成（状态「ready」）时，「立即更新」才会出现；下载失败不会留下半更新状态。

### 十、更新方式（已有安装）

- 解压目录内新增 `更新.cmd`：双击后自动检查 GitHub 最新版本，比较版本号，下载对应的 `the-veil-vX.Y.Z.zip` 与 `.sha256`，校验通过后只替换程序文件，保留 `data/`（剧本、账号、日志、插件数据）与 `.venv`，完成后提示重新启动。
- 命令行可用：

  ```powershell
  powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\update-release.ps1
  ```

  可选参数：`-CheckOnly` 只检查不更新；`-Force` 允许同版本重装；`-SkipBackup` 跳过 `data/` 备份（不推荐）。
- 更新脚本会在替换前把 `data/` 复制到 `_backup/<版本>-<时间>/`；如果新版本启动失败，可用备份目录覆盖回去。
- 手工更新同样可行：下载新包解压到新目录，把旧目录的 `data/` 整个复制过去即可。
