# v0.5.0b

发布日期：2026-10-18

变更时间：2026-10-18

本次更新项目更名为「帷幕 The Veil」，新增「无需预装 Python」的一键启动脚本与控制台运维命令体系；修复本地 Embedding 后端反复加载失败，并改为「本地优先、云端可选」；围绕 AI 成本与可观测性完善 token 归因、缓存命中、小模型分层与传输重试，同时加固「守剧本」护栏；另修复 AI 工具调用函数名不合法、平台配置保存丢字段、内置平台重复添加互相顶替等一批问题。发布包前缀由 `aibasedtrpg` 改为 `the-veil`，并新增随包的第三方依赖许可证清单。

## 品牌与部署

- 项目更名为「帷幕 The Veil」：程序本体、前端文案与 README / wiki 统一品牌来源（运行时 `site.json` + 前端文案），中文界面不再中英并列。
- 新增一键启动：`start.cmd` + `start-bootstrap.ps1`，**无需预先安装 Python**——自动定位或安装 Python 3.11+、创建 `.venv`、安装依赖、按需构建前端，并用依赖指纹跳过重复安装，第二次启动几秒即可；支持 `-Force` / `-DryRun` / `-IndexUrl`。
- `start.cmd` 为纯 ASCII + CRLF + 无 BOM，规避双击窗口一闪而过；两个启动脚本输出统一为后端日志格式（`[时间][级别][线程] 消息`），便于与服务日志对照阅读。
- `requirements.txt` 补全 `requests`，修复服务启动即 `ModuleNotFoundError`。

## Embedding 后端

- 本地模型后端仅在「模型目录存在且 `sentence-transformers` 可导入」时选用，不再选中必然加载失败的后端并反复打印 `embedding_model_load_failed`。
- 云端 Embedding 接口默认关闭，改由管理员在设置页开启（`general.toml` 的 `[ai] cloud_embedding_enabled`）；退化到哈希兜底时打印 `embedding_backend_degraded`，便于观测。
- 一键启动脚本在检测到本地模型目录且依赖缺失时自动补齐 `sentence-transformers`（`torch` 走 CPU 专用源，避免默认拉取数 GB 的 CUDA 版本）。

## AI 成本与可观测性

- **token 归因与分段统计**：新增本地 token 估算与输入分段统计；控制台新增 `ai usage [days]` 命令；仪表盘展示缓存命中率与分段成本。
- **修复缓存几乎永不命中**：状态指纹新增 `stable_state_for_cache` 稳定投影，剔除 uuid / 时间戳等易变字段。
- 仅对无副作用的玩家输入启用缓存读写（检定 / 触发 / 转场请求不走缓存），确保不削弱 KP 对剧本的遵守。
- 新增 `[ai.cache]` 可调参数（语义 / 精确缓存开关与 TTL）。
- **小模型分层**：`general.toml` 的 `[ai.small_models]` 覆盖真正生效（`resolve_task_model`），摘要 / 状态更新 / 意图分类走小模型；各平台 JSON 补齐 `small_models`，`aliyun` 补齐 `embedding` 配置。
- **传输层**：抽出 `agents/http_retry.post_with_retry`，chat/completions 与 Responses API 共用按预算重试逻辑；Responses API 增量传输（`previous_response_id`）遇瞬时抖动不再永久降级，重试耗尽才回退；超时错误上报真实等待秒数。
- **守剧本护栏**：KP 引用剧本外的场景 / NPC / 线索 / 物品被丢弃时写入 warning 日志，便于发现编造；新增结构化输出丢弃告警测试。

## 设置与控制台

- 设置页新增工具调用去重、本地响应缓存开关与 TTL 等可调参数（均经保存确认后生效）。
- 新增 `server` / `user` / `ai` / `vector` / `knowledge` / `room` / `network` / `backup` / `scenario` 等控制台运维命令：均为独立非 Flask 模块，破坏性命令默认预演、交互确认并支持 `--yes` 跳过；同步更新命令注册与文档。
- 新增 Vector / Knowledge 巡检与孤儿向量清理，补齐控制台命令文档（`docs/console-commands.md`）。
- 房间成员在线判定（`is_user_in_room`）、`must_change_password` 会话下发、平台加载顺序 `ordered_platform_paths`。

## AI 平台配置

- 内置 DeepSeek 模板与部署向导的模型名对齐官网：`deepseek-flash`（默认）与 `deepseek-v4-pro`，移除官网并不存在的 `deepseek-chat`。
- **修复重复添加内置平台互相顶替**：同一个内置供应商可重复添加，平台 id 已被占用时自动编号并改名（如 `deepseek` → `deepseek-2` / `DeepSeek 2`），两个平台并存。
- **修复保存平台配置静默丢字段**：前端整对象回写时保留 `small_models` / `embedding` 等扩展段，避免保存平台后小模型路由与云端 embedding 配置被清空。

## 修复

- AI 工具调用函数名不再使用 `.` 作为命名空间分隔符：下发时统一替换为 `_`，满足厂商 `^[a-zA-Z0-9_-]+$` 校验（修复 DeepSeek 平台下创建房间报 HTTP 400）。
- 头像与剧本封面：移除随包的内置默认图片，改为前端按名称即时生成文字化 SVG data URI，历史默认图字段做幂等迁移。
- 聊天输入框关闭浏览器原生历史输入补全。
