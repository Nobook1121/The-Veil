# v0.5.0

发布日期：2026-10-17

变更时间：2026-10-17

本次发布完成品牌重塑：项目由「AIBasedTRPG」正式更名为「帷幕 The Veil」，仓库地址改为 `github.com/Nobook1121/the-veil`，中文界面文案统一显示「帷幕」（英文界面为 The Veil，不再中英并列）；新增 Windows 一键启动脚本 `start.cmd`（不受 PowerShell 执行策略限制，取代原 `start.ps1`）；修复 DeepSeek 等严格校验 function name 的平台在开始剧本时调用工具报 400 的问题；同步更新 API 文档与发布包说明。

## 品牌与项目更名

- 项目更名为**帷幕 The Veil**：README、后端包/路由文档字符串、前端 `setup-wizard` 标题、侧边栏与首页文案同步更新。
- 中文界面统一显示「帷幕」，不再中英并列；英文界面显示 “The Veil”。`app.title` / `app.title.full` / `home.welcome` 与 legacy 历史文案映射一并更新。
- 站点默认名由 `"AI TRPG"` 改为 `"帷幕"`（`data/config/site.json`）。

## 启动方式

- 新增 `start.cmd`（Windows 一键启动）：双击即可运行，不受 PowerShell 执行策略限制；自动优先使用 `.venv` 内的 Python、设置 UTF-8 输出、找不到 Python 时给出提示；支持传参指定端口（`start.cmd 8090`）。
- 移除 `start.ps1`，README 的安装 / 启动说明同步改为 `activate.bat` 与 `start.cmd`。

## AI 运行时修复

- **修复 DeepSeek 平台开始剧本报 400**：项目内部工具 id 采用点号命名空间（如 `room.get_room_snapshot`），而 DeepSeek / OpenAI 要求 function name 匹配 `^[a-zA-Z0-9_-]+$`，直接发送会被平台拒绝。修复后：
  - 对外发送的工具 schema 把点号规整化为下划线（`room_get_room_snapshot`）；
  - 回传给模型的 assistant `tool_calls` 与 `tool` 消息的 `name` 一并规整化，避免后续每一轮请求再被拒；
  - 解析模型调用时，内部 id 与规整化名均可映射回同一个工具（模型按提示词里的点号 id 发起调用也能正确解析）。
- 新增回归用例，校验所有默认工具 schema 名符合平台字符集要求。
