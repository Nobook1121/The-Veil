# v0.5.15a

## AI 对话语音配音（P2）：本地多音色 TTS

改动时间：2026-11-03 20:51（Asia/Shanghai）

### 玩家可见变化

- 新增 `local` 引擎：管理员安装 Kokoro v1.1-zh 权重并开启后，9 个内置人设使用真实说话人合成 24kHz WAV，而不再只靠 pitch/rate 区分。
- 男/女清晰可分，少年/青年/中年/老年各有可辨识音色；同一 profile 每回合稳定命中同一 `speaker sid`。
- 本地合成失败、子服务崩溃、超时或未安装权重时，自动降级回浏览器音色（`local → system → 仅文字`），播放与打断/排队/ducking/单条重播/按 NPC 静音行为不变。
- 设置页新增「本地多音色引擎」区块：状态、安装、移除、模型 ID、子服务地址、并发、超时、人设映射与缓存配置；首次启用未安装会明确提示并可一键安装。

### 引擎形态

- 合成子服务为独立 `127.0.0.1` 回环进程（`trpg_server.voice.local_worker`），提供 `/health`、`/voices`、`/synthesize`，不占用 Flask 主进程。
- 主进程适配层 `engine.py` 签名不变，`director.py` 不感知引擎切换；`local_service.py` 负责生命周期、健康缓存、并发闸门与缓存编排。
- 语音与实时配图共用 `task_gate`：同一时刻有生图任务时语音排队，不抢 CPU/显存；并发默认 1，可配 1–8。
- 降级原因具体化：`local_disabled` / `local_model_missing` / `local_unavailable` / `local_timeout` / `local_error`。

### 选型与许可证

- 采用 `sherpa-onnx 2.0.1`（Apache-2.0）+ `kokoro-int8-multi-lang-v1_1`（Kokoro-82M-v1.1-zh，Apache-2.0，103 说话人，24kHz）。
- 排除 AISHELL-3 VITS 多说话人导出：数据集虽为 Apache-2.0，但导出模型仅 8kHz，音质与年龄区分不达标。
- 排除任何 CC-BY-NC / CC-BY-NC-SA / 来源不明的中文权重。
- 权重不入库、不随发布包分发；运行时下载到 `data/runtime/voice/models/<模型>/`，并写入 `INSTALL.json` 与 `LICENSE.txt`。

### 配置

新增 `[immersive]` 配置：`voice_local_enabled`、`voice_local_base_url`、`voice_local_model`、`voice_local_concurrency`（默认 1）、`voice_local_timeout`（默认 30）、`voice_local_speakers`、`voice_cache_enabled`、`voice_cache_quota_mb`（默认 64）、`voice_cache_max_entries`（默认 300）、`voice_cache_overflow`（默认 lru）。房间只能收紧，不能开启站点未开放的引擎，缓存只能清理本房间。

### 缓存

- key：`sha256(engine | model | voice_id | speed | format | 归一化文本)`，归一化只处理首尾与连续空白，保留标点。
- 落盘 `data/rooms/<room_id>/immersive_cache/voice/`，随房间归档保留；临时文件 + 原子替换，降级或空音频不写缓存。
- 默认 64MB / 300 条；超限 `lru` 或 `reject`；同秒写入使用单调 `seq` 保证真正的 LRU 顺序。
- 命中不调用引擎、不计耗时，日志标 `cache_hit`。

### 命令

站点（默认预演，`--yes` 执行）：

```text
voice local status|install|remove|model|base-url|concurrency|timeout
voice cache stats|clear|prune
```

房间（默认预演）：

```text
voice cache stats|clear|prune [--yes]
```

安装/卸载/切换引擎仅站点管理员；房间只能查看状态与清理本房间缓存。

### 新增依赖

`requirements.txt` 新增 `sherpa-onnx==2.0.1` 与 `numpy`；许可证登记见 `THIRD-PARTY-LICENSES.md`。

### 已知限制

- 本机 8 核、并发 1 时 RTF 约 1.2，CPU 合成略慢于实时；依赖前端逐段流水、缓存与 30 秒超时兜底。
- 云端引擎仍为占位；未实现多引擎并行或 GPU 推理。
