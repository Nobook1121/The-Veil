# v0.5.1b

发布日期：（待发布）

变更时间：2026-10-20 23:12

本次更新为首次部署引导新增「准备 Embedding 模型」步骤（自动下载 / 拖入上传 / 云端接口三选一），并把下载用的模型仓库改为 `general.toml` 可配置项，代码与前端文案里不再写死仓库名；同时新增全局「约束最大输出 token」开关与统一 AI 请求封装，角色卡 AI 生成也收敛为独立模块并新增控制台自测命令。

## 首次部署引导（Embedding 模型）

- 向导由 5 步扩为 6 步，第 2 步「准备 Embedding 模型（可跳过）」提供三种方式：程序自动下载（后台线程，官方站失败自动回落镜像）、拖入模型文件夹 / `.zip` 压缩包上传、复用已配置的 AI 平台改用其 embedding 接口；跳过按钮与其它步骤保持一致。
- 新增独立模块 `setup_embedding.py`（下载任务状态机、仓库文件枚举、zip / 散文件落盘、`general.toml` 开关写入）与 `routes/setup.py` 的 4 个接口（status / download / upload / cloud）；新路径加入 CSRF 与会话豁免名单。
- 引导上传体积上限独立为 `SETUP_EMBEDDING_UPLOAD_MAX_BYTES`（256 MB），全局 `MAX_CONTENT_LENGTH` 改为取各功能上限的最大值，不再由剧本导入上限单独决定。
- **模型仓库不再写死**：默认值改由 `general.toml` 的 `[ai] local_embedding_repo` 决定（代码内仅保留兜底默认值），`GET /api/setup/embedding/status` 回传当前生效值，引导页据此动态显示仓库名，前端文案不再硬编码仓库名。
- 本地模型与云端 Embedding 都在程序下次启动时生效。

## 全局最大输出 token

- `general.toml` 的 `[ai]` 新增 `constrain_max_tokens`（默认开启）与 `max_tokens`（默认 16384）：未在请求模板里自行声明的请求统一按该值下发，模板里显式写了 `max_tokens` 的以模板为准；关闭开关则不下发 `max_tokens`，输出上限交给平台自身。默认取宽裕值是为了避免靠压缩输出预算省 token 而截断回复。
- 新增 `agents/ai_request.py` 统一请求封装，KP 对话、模块摘要、剧本处理、平台探测与角色卡生成共用；管理员设置页新增「最大输出 Token（全局）」区块，保存确认后生效。

## 角色卡与控制台

- 角色卡 AI 生成逻辑收敛到 `character_ai.py` 独立模块（原 `routes/character_ai.py` 只保留 HTTP 壳），并新增 `ai character generate` 控制台自测命令（支持 `--scenario` / `--json`，失败返回 `platform` / `timeout` / `connection` / `empty_content` 分类）。
- 修正 `docs/console-commands-plan.md` 中 `autosave` 与 `owner transfer` 两行：补回 `[--yes]` 标记、修正复用实现名称、清理误入的乱码字符。

## 房间内嵌控制台（网页内，变更时间 2026-10-20 15:04）

- 新增房间内嵌 Web 控制台：只显示**本房间**日志，房间事件默认写入房间目录下的 `console.jsonl`，**不再刷服务器启动窗口**，消除自动存档等高频日志噪音。
- 新增无 Flask 依赖的 `room_log.py`（JSONL 追加写 + mtime 缓存 + 线程锁 + 原子替换 + 超限裁剪 + 脱敏 + 可选镜像回服务器控制台），并新增房间级命令执行器 `room_console_commands.py`（严格白名单，站点级命令一律拒绝）与 REST 蓝图 `routes/room_console.py`。
- 迁移房间事件日志调用点（`routes/rooms.py` / `socket_events.py` / `routes/chat.py`）改用 `log_room_event`，默认只落房间日志；`data/config/general.toml` 新增 `[room_console]` 段（启用开关 / 镜像开关 / 条数上限 / 查看与执行角色）。
- 房间归档快照新增 `console_log` 字段，房间日志随房间一并归档。
- 前端新增 `room-console.ts` 面板（房间详情页）、`room_console_log` 实时事件接线、管理员设置页「房间控制台」控件与 14 个中英文案键。
- 新增测试 `tests/test_room_console_store.py` / `test_room_console_commands.py` / `test_room_console_routes.py` / `test_room_console_archive.py`（共 48 例）。
- 修复（变更时间 2026-10-20 19:46）：房间控制台输入 `help` 会反复弹出「确认执行」弹窗——原因是用返回文本里是否含「预演」二字来判断破坏性命令，而帮助文本本身含该词；改为依据命令本身判断（仅 `log clear` / `archive` 且未带 `--yes` 时才走「预演 → 确认」）。同时移除命令结果路径上的所有 `showNotification` 弹窗，warning / error 级别结果只在房间控制台内显示。
- 调整（变更时间 2026-10-20 20:18）：房间控制台输出区支持自动换行（`pre-wrap` + `overflow-wrap: anywhere`），长命令结果不再被横向截断；删除面板底部「日志记录在房间目录内…」提示文案及其 i18n 键。
- 新增（变更时间 2026-10-20 20:18）：房间控制台新增 `members kick <user> [--yes]`（移出房间成员，不可移出房主）与 `members promote <user> [--yes]`（仅提升为房间管理员，不能提升为房主或网站级 ADMIN/OWNER，独立实现、不复用网站控制台）。
- 收紧（变更时间 2026-10-20 20:18）：房间控制台改为只对网站管理员/所有者与房间所有者/房间管理员显示，普通房间成员既看不到面板也无法通过接口读取（`view_role` 默认由 `member` 调整为 `admin`）。
