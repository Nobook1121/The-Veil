本次更新把「世界意志」弹窗（`#worldOverrideModal`）按主题做了分别适配。弹窗仍由 React 通过 `createPortal` 挂载在 `document.body`，结构不变；所有样式规则都限定在该弹窗与对应主题下，不影响其他弹窗、聊天区与页面。

## 深渊帷幕：法阵与虚化遮罩

变更时间：2026-11-02 22:20

- 修改 `frontend/src/app/worldOverride.ts`：
  - `runeRing` 新增 `idPrefix` 与 `darkOutline` 参数，同半径的实线符文环与柔光符文环使用不同路径 id，避免 `url(#id)` 冲突。
  - 符文增加极细深色描边（`paint-order: stroke fill`），环带自发光再亮也不会糊掉字形。
  - 新增 `world-override-sigil-aura` 大半径柔光层，与 halo 层一起构成「环带自发光」；两层内嵌无描边符文作为底光。
  - 新增 `veilEnabled()`：法阵只在 `body.theme-coc` 下创建与显示，其它主题打开世界意志时不生成任何背景特效。
- 修改 `frontend/src/styles/06-combat-world-override.css`：
  - 基础弹窗改为 flex 纵向布局，`max-height: calc(100dvh - 24px)`，正文区独立滚动，窄屏下输入区与按钮不被顶出屏幕。
  - 法阵层全部限定在 `body.theme-coc`；尺寸改为 `min(max(100vmin, 640px), 980px)`，手机上法阵仍宽于弹窗。
  - 三层刻线只做 `transform` 旋转，aura / halo 为静态模糊层，不逐帧重绘。
  - 新增 `prefers-reduced-motion` 降级，关闭法阵与光晕动画。
- 修改 `frontend/src/styles/07-theme-abyss-tokens.css`：新增 `--theme-veil-alpha`（默认 0.55）与 `--theme-veil-blur`（默认 10px）。
- 修改 `frontend/src/styles/08-theme-abyss-components.css`：
  - `body.theme-coc .modal-backdrop.world-override-backdrop` 的 z-index 压到 1040，法阵层保持 1049，弹窗 1050+，修复法阵被整屏 `backdrop-filter` 糊掉的问题。
  - 遮罩改为半透明 + `backdrop-filter: blur()` + 轻微青绿/暖金渐变；`.show` 的透明度固定为 1，避免 Bootstrap 的 0.5 再把配置值砍半。
  - `@supports not (backdrop-filter)` 时回退为更实的暗色遮罩，保证文字对比度。

## 赛博档案：终端指令面板

变更时间：2026-11-02 22:20

- 修改 `frontend/src/styles/10-theme-cyber-components.css`：
  - 新增世界意志终端样式：顶部 30px 命令行标题条（`OVERRIDE.EXE // ROOT ACCESS // NODE 07` + 三色指示灯）、静态扫描线、`>` 提示符与光标块、`//` 注释式提示、等宽输入框、磷光青霓虹描边。
  - 执行按钮为磷光青实心深色字，取消按钮为暗底青边；关闭按钮反转为可见的青色。
  - 遮罩 `z-index: 1040`、半透明 + blur + 静态扫描线纹理，`@supports` 回退。
  - 新增 `body.theme-cyber-2.light-theme` 纸质终端配色：纸白底、深翡翠边框与文字，避免浅色下文字发白、边框消失。
  - 窄屏（≤576px）缩短标题条文案与高度；`prefers-reduced-motion` 关闭光标闪烁。
  - 唯一持续动画是标题旁的光标块，不使用满屏动画。

## 已知限制

- 赛博档案当前运行时只使用深色配色；`body.theme-cyber-2.light-theme` 的浅色终端配色为兼容预留，需要主题选择器将来提供浅色变体才会生效。
- `backdrop-filter` 在部分旧浏览器不可用，此时遮罩会回退为更实的暗色，背景场景不再可见，但弹窗对比度不受影响。
- 极窄屏（宽度 <360px）下赛博标题条文案会被省略号截断，属于预期行为。
