# v0.5.5b

发布日期：（待发布）

变更时间：2026-11-02 18:20

本次更新新增两套与叙事实时联动的沉浸系统：可离线运行的实时配乐，以及默认程序化、可切换外部服务的实时配图。两套系统均接入房间、房规、系统设置、控制台与日志，并在失败时优雅降级，不阻塞主叙事流程。

## 实时配乐（Web Audio 程序化作曲）

变更时间：2026-11-02 18:20

- 新增 `backend/trpg_server/immersive/analyzer.py`：确定性叙事氛围分析，中文关键词权重 + 感叹号/省略号强度 + 结构化场景优先，低置信度回落到管理员默认档位。
- 新增 `backend/trpg_server/immersive/music.py`：配乐导演状态机，支持切换滞回、紧张度跨级快速升级、每 4 回合段落推进、手动指令，以及 `base_seed:section` 可复现种子。
- 新增 `frontend/src/app/immersive/music-engine.ts`：8 套氛围档位 × 3 档强度的 Web Audio 合成器；振荡器/噪声/卷积混响/BiquadFilter；A/B 总线交叉淡入淡出；每小节以播种确定性 PRNG 生成动机与配器变化；自动播放受限时等待用户手势解锁。
- 修改 `frontend/src/app/bgm.ts`：新增 `setDuck()`，沉浸配乐播放时把原房间 BGM 音量压到 30%，停止/静音后恢复。
- `immersive_status()` 返回进房恢复所需的档位、段落、种子、场景、交叉淡入、音量与压低设置；前端 `planFromState()` 重组计划，进房即恢复配乐。

## 实时配图（默认程序化 SVG，可切换 OpenAI 兼容）

变更时间：2026-11-02 18:20

- 新增 `backend/trpg_server/immersive/svg_scene.py`：1280×720 确定性场景 SVG（调色板、山脊、雨/余烬/星点、光晕与场景标签），同一档位/强度/场景/种子永远生成同一张图。
- 新增 `backend/trpg_server/immersive/illustration.py`：图片缓存、每日预算与房间小时配额预留、后台线程池、外部生图、历史记录与路径穿越防护；任何失败回落程序化图并带 `degraded` 原因。
- 新增 `backend/trpg_server/immersive/service.py`：叙事回合编排入口 `on_narrative_turn`（永不抛错）、手动配乐指令、立即配图与房间状态汇总。
- 新增 `backend/trpg_server/immersive/broadcast.py`：Socket.IO 广播注入，避免沉浸模块直接依赖 Flask。
- 修改 `backend/trpg_server/routes/chat.py`：在叙事响应返回前调用 `on_narrative_turn`，异常只记日志。
- 新增 `frontend/src/app/immersive/illustration.ts` 与 `frontend/src/styles/11-immersive.css`：聊天页场景画面面板、生成中 shimmer、失败保留上一张、最近 8 张历史缩略图、自建 lightbox（非原生 alert）、移动端 4:3 适配与 `prefers-reduced-motion` 降级。
- 修改 `frontend/src/react/home/HomeChat.tsx`：在战斗面板与聊天历史之间插入 `#immersiveStage`。
