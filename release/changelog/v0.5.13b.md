# v0.5.13b

## 音乐来源可配置 + 音乐库并入实时沉浸

改动时间：2026-11-03 13:07（Asia/Shanghai）

### 新增配置

- `immersive.music_source`：音乐来源三档 `realtime` / `bgm` / `hybrid`，默认 `hybrid`。
  - `hybrid` 维持既有行为：实时程序化配乐为主层，原 BGM 压低为底噪。
- `immersive.music_source_allowed`：个人可选来源白名单（逗号分隔），默认三档全开。
- `immersive.music_source_allow_personal`：是否允许个人覆盖，默认开启。

以上字段已进入 `backend/trpg_server/config/schema.py` 与 `config/templates/general.toml`，`test_config_template_sync.py` 双向同步通过。

### 行为

- 仅 BGM（`bgm`）：不创建实时配乐的 AudioContext，不启动调度；切换到该档位时会先淡出再销毁上下文。
- 仅实时配乐（`realtime`）：原 BGM 淡出到 0 并暂停。
- 混合（`hybrid`）：实时配乐为主层，BGM 按既有 ducking 规则压低到 30% 音量。
- 切档 600ms 淡入淡出，切回仅 BGM / 混合时按原音量与播放状态恢复。
- 房间侧沿用三态房规：`immersive_music_enabled = off` 会强制该房间回到仅 BGM，房间不能放宽站点/个人设置。

### 界面

- 「设置 → 实时沉浸」新增音乐来源、个人可选范围、是否允许个人覆盖三项。
- 「设置 → 音乐库」标签页已移除，内容整体并入「实时沉浸」标签卡（上传、列表、试听、删除）。
- 旧 `#settings-bgm` 书签自动重定向到「实时沉浸」。
- 个人主页「个人设置 → 沉浸偏好」新增音乐来源选择（仅本地存储、受站点允许范围限制）。
