# v1.0.2

## 设置页重构：八类信息架构、卡片布局与「关于」页

改动时间：2026-11-10（Asia/Shanghai）

### 版本

- 应用版本统一为 **1.0.2**，唯一真源为 `backend/trpg_server/version.py` 的 `APP_VERSION`。
- `package.json`、发布脚本、部署文档与安装说明中的版本号同步更新；历史 changelog 不改写。

### 一、信息架构

设置页从 10 个横向标签整理为 8 个分类，左侧为分类轨，右侧为搜索与内容区：

| 新分类 | 内容来源 |
| --- | --- |
| 基础 | 原「常规设置」+「主题」 |
| 游玩 | 原「角色卡规则」+ 自动保存、房间控制台、房间回收、世界意志、骰娘 |
| 模型与 AI | AI 平台、模型、密钥、Token 与用量、站点 Agent |
| 知识库 | 规则书/剧本知识库、检索与记忆 |
| 系统与网络 | 网络配置、启动与部署相关项 |
| 用户与权限 | 原「权限配置」+「用户管理」 |
| 实时沉浸 | 原「实时沉浸」+「音乐库」 |
| 关于 | 全新页面 |

- 旧链接、旧书签与 `#settings-theme` 等 hash 在深链接入口一次性迁移到新分类并改写地址，不保留运行时别名兼容。
- 「关于」页提供版本、构建方式、提交、构建时间、通道、运行时、许可证、仓库入口、更新检查与致谢。

### 二、界面与交互

- 设置内容改为卡片分区，每张卡片带标题、说明与作用域标记（个人偏好 / 站点配置 / 部署级）。
- 顶部工具栏集中搜索框、保存状态条与「回到顶部」按钮；分类轨支持 `↑` / `↓` / `Home` / `End` 键盘切换。
- 设置搜索可匹配标题与说明，命中后自动切换到对应分类并滚动定位；原「说明」折叠保留。
- 存在未保存修改时，对应分类显示脏点，底部保存条同步出现。
- 部署锁定（环境变量强制）的设置在界面上保持只读，并说明锁定来源。

### 三、关于页与更新检查

- 新增公开接口 `GET /api/app/info`、`GET /api/app/update`；检查与下载接口需要 `settings.general` 权限。
- 更新检查读取 GitHub Releases：展示状态、当前/最新版本、发布说明与下载进度。
- 下载完成后**不会自动替换程序目录**，需用户手动解压替换并重启；界面明确提示这一点。
- 更新源与行为写入配置 `[update]`：`repo`、`channel`、`request_timeout_seconds`、`check_update_on_startup`、`auto_update`。
- 设置 `AI_TRPG_DISABLE_UPDATE_CHECK=1` 可完全停用检查；`update` 段对站点 Agent 只读，防止改下载源。
- 发布包生成 `backend/trpg_server/build_manifest.json`；运行时优先读取 `data/runtime/build.json`。

### 四、删除与合并的旧设置项

- 删除独立的「主题」「角色卡规则」「网络配置」「权限配置」「用户管理」「音乐库」标签入口，内容分别并入上表的新分类。
- 移除旧设置页顶部横向标签结构，替换为分类轨；旧 hash 由深链接入口迁移，未知或不可用分类回落到「基础」。
- 关于页的赞助信息只来自 `resources/credits.json`，不再维护第二份来源。

### 五、收尾修正

- Embedding 状态改由 `GET /api/vector/health` 提供 `ready`、`fallback` 与向量库最近索引时间；前端自绘状态条，颜色全部使用主题 token，仅在进入知识库、手动刷新与索引完成后拉取，不轮询。
- 模型面板移除平台列表的固定高度与内层纵向滚动，统一随设置内容区单层滚动，平台数量多时仍可顺序操作。
- 移除 `switchSettingsTab` 的旧分类别名；旧 hash 在鉴权完成后一次性迁移并改写为新分类地址。

### 六、验证

- `npm run typecheck`、`npm run build:frontend` 通过。
- `pytest tests -q` 通过；新增应用信息、更新服务与 Embedding 健康字段测试。
