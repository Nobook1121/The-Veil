本次更新调整实时沉浸的界面布局：把「场景画面 + 配乐/沉浸控制」面板从聊天流移到右侧栏底部，并为右侧栏增加可持久化的收起/展开交互。聊天区因此恢复为纯对话、战斗面板与输入区；窄屏下同一面板会移回聊天区，不会消失。

## 场景面板停靠右侧栏

变更时间：2026-11-02 23:20

- 修改 `frontend/src/react/home/HomeChat.tsx`：
  - 删除聊天区里由 React 渲染的 `#immersiveStage` 整段，替换为空的 `#immersiveChatStageHost` 宿主。
  - 右侧栏拆为 header、`.home-room-members-body`（成员列表 + `#immersiveSidebarStageHost` 停靠点）与收起后的窄轨。
  - 成员列表保持 `flex: 1 1 auto; overflow-y: auto`，沉浸停靠区独立滚动，二者互不挤压。
- 修改 `frontend/src/app/immersive/illustration.ts`：
  - 新增 `ensureStage()`：面板 DOM 由脚本创建一次并常驻，React 只提供宿主；避免断点切换时重建 DOM 导致按钮与图片监听丢失。
  - 新增 `mountStage()`：按 `matchMedia("(max-width: 767.98px)")` 在 `#immersiveSidebarStageHost` 与 `#immersiveChatStageHost` 之间移动同一节点；宿主晚挂载时最多重试 20 帧。
  - 监听断点 `change`，在桌面/移动布局间自动迁移面板。
  - `updateButtons()` 同步窄轨配乐图标的 `data-muted` 与 `aria-pressed`。
- 修改 `frontend/src/styles/11-immersive.css`：右侧栏停靠态改用 4:3 画幅（`object-fit: cover`，不拉伸），缩小按钮与标题字号，历史缩略图 `flex-wrap: wrap`（64×42）。
- 修改 `frontend/src/styles/01-foundation-chat.css`：新增 `.home-room-members-body`、`.immersive-sidebar-stage-host`（`max-height: min(56%, 380px)`、自身滚动、`overscroll-behavior: contain`），以及右侧栏收起/窄轨样式。

## 右侧栏收起与展开

变更时间：2026-11-02 23:20

- 修改 `frontend/src/react/home/HomeChat.tsx`：
  - 新增 `SIDEBAR_COLLAPSED_STORAGE_KEY = "trpg.homeSidebar.collapsed"`，初始状态从 `localStorage` 读取，变更时写回；隐私模式下存储不可用时仅本次会话生效。
  - 成员栏标题旁新增 `#homeRoomMembersCollapse` 按钮（`aria-expanded` / `aria-controls`）；收起后窄轨保留 `#homeRoomMembersExpand` 展开把手与 `#homeRoomMembersRailMusic` 配乐开关。
  - 新增 **Alt+B** 全局快捷键切换收起状态，输入框内同样生效。
- 修改 `frontend/src/styles/01-foundation-chat.css`：
  - `.home-room-members.is-collapsed { flex-basis: 48px; }`，`transition: flex-basis 180ms ease`；收起时隐藏 header 与 body，只显示窄轨。
  - 窄轨按钮 30px/34px、焦点描边、静音态暖色描边；`prefers-reduced-motion: reduce` 时关闭过渡。
- 修改 `frontend/src/app/immersive/index.ts` 与 `frontend/src/types/immersive.d.ts`：
  - 暴露 `window.TrpgImmersive.toggleMusic()` 与 `syncMusicButton()`，供窄轨按钮调用并在 React 重新渲染后同步状态。
  - 初始化时主动同步一次窄轨图标，覆盖「刷新时侧栏已收起、主按钮不存在」的情况。

## 已知限制

- ≤767.98px 时右侧栏（含成员列表）整体隐藏，这是面板退回聊天区的配套策略；移动端暂未提供独立的成员抽屉。
- 收起后的窄轨只保留展开把手与配乐开关；历史缩略图、重新配图等操作需要展开侧栏。
- `localStorage` 不可用（隐私模式/禁用存储）时，收起状态只在本次会话生效。
- 右侧栏最窄 210px 时，4:3 画幅约 142px 高，画面按 `object-fit: cover` 裁切，极端长图可能裁掉边缘细节。
