# v1.0.3

## 团录导出 PDF：三套版式、导出接口与前端联调

改动时间：2026-11-12（Asia/Shanghai）

### 版本

- 应用版本统一为 **1.0.3**，唯一真源为 `backend/trpg_server/version.py` 的 `APP_VERSION`。
- 历史 changelog 不改写。

### 一、团录导出（P0–P4）

新增完整的房间团录导出链路：从 `messages.json` 生成中文、可搜索、带目录页码的 A4 PDF。

- **归约（P0）**：新增 `room_log/model.py`，按日期切章、同日超过 250 条二次切章、保留场景扩展位；过滤 OOC、映射骰子判定、降级缺失图片、统计章节/条数/骰子/图片/跨度/预估页数。
- **安全 Markdown（P0）**：`room_log/markdown.py` 只支持标题、粗体、斜体、引用、列表、行内代码、分隔线；先转义再替换，并做标签白名单过滤，`<script>` 等原始 HTML 一律转义。
- **字体（P0）**：`room_log/fonts.py` 探测黑体/雅黑/宋体或 `data/assets/fonts/`，验证可打开且含汉字后嵌入；找不到可用字体时抛 `FontMissing`，绝不生成方块字 PDF。
- **渲染（P1）**：`room_log/render.py` 使用 PyMuPDF `Story`，每章独立渲染取得真实页码，再合并封面、目录与正文；页脚统一写入「第 n 页 / 共 m 页」。视觉只使用 `table`、`border`、`background-color` 等 Story 支持子集，不依赖 flex/grid/绝对定位/浮动/阴影/圆角/变换/滤镜/SVG/分栏。
- **任务（P2）**：`room_log/jobs.py` 提供有界线程池、`queued/running/done/failed` 状态机、进度回写与按天保留清理；产物写入 `data/runtime/logs/exports/<room_id>/<export_id>.pdf`。
- **接口（P2）**：新增蓝本 `routes/room_log.py`：
  - `GET /api/rooms/<room_id>/log/preview`
  - `POST /api/rooms/<room_id>/log/exports`
  - `GET /api/rooms/<room_id>/log/exports/<export_id>`
  - `GET /api/rooms/<room_id>/log/exports/<export_id>/file`
  - `DELETE /api/rooms/<room_id>/log/exports/<export_id>`
- **权限（P2）**：房主/房管/站点管理员始终可导出；普通成员由 `members_can_export` 控制。preview、创建导出、下载文件三处使用同一套校验。preview 返回 `can_export` 与 `can_export_reason`（`members_disabled` / `font_missing`）。
- **错误码**：`log.empty`、`log.font_missing`、`log.render_failed`、`log.forbidden`、`log.invalid_option`、`log.export_not_found`、`log.not_ready`。字体缺失时 preview 仍返回 200（禁用导出），创建导出返回 503。
- **配置**：新增 `[room_log]`：`enabled`、`members_can_export`、`default_template`、`include_ooc`、`include_dice`、`include_images`、`max_messages_per_export`、`keep_exports_days`、`max_concurrent_exports`、`font_file`；已同步 schema、模板配置与配置同步测试。

### 二、三套版式（P4）

| id | 名称 | 特征 |
| --- | --- | --- |
| `archive` | 档案卷宗 | 深墨绿封面 + 烫银线框、卷宗内页、目录、旁白/台词竖线、骰子浅底表格 |
| `letter` | 手记信纸 | 无独立封面与目录，首页即抬头（房间名/剧本名/日期），段首全角缩进，章节间 `＊　＊　＊` 分隔，玩家发言书信摘录样式 |
| `minimal` | 极简排版 | 白底黑字、无装饰，页眉细线 +「房间名 · 团录」，骰子与系统消息压成行内灰字，保留目录 |

- 三套模板共用 `template.json` / `cover.html` / `chapter.html` / `print.css` 结构与同一套可用性检测；`template.json` 的 `name` / `description` 通过 preview 的 `templates` 数组暴露。
- 真实房间（180 条、2 章）实测：`archive` 44 页 / 348 KB，`letter` 45 页 / 388 KB，`minimal` 34 页 / 329 KB；均中文可提取、无方块字，目录页码与实际章节起始页一致。

### 三、设置页集成与前端契约（同版本）

- 设置页新增 `[room_log]` 配置分组（由设置页重构会话完成），包含开关、默认模板、图片/骰子/OOC 默认项、条数上限、保留天数、并发数、字体路径与成员导出权限。
- 前端团录导出模态与本版本后端契约对齐：
  - preview GET query：`template`、`include_dice`、`include_ooc`、`include_images`、`include_kp_only`、`date_from`、`date_to`；布尔使用 `1/0`，日期 `YYYY-MM-DD`。
  - `stats.estimated_pages` 提供页数预估，替换前端「消息数 / 33 + 2」的硬估算。
  - `templates` 返回 `{id, name, description, available}`，字体缺失时模板标记不可用。
  - 权限以 preview 返回的 `can_export` / `can_export_reason` 为准，入口与生成按钮据此显示或禁用。

### 四、验证

- 定向测试：`tests/test_room_log.py` 覆盖归约、Markdown 注入、字体缺失、三模板渲染、权限/空房间/503/下载接口；配置、权限与角色相关定向测试通过。
- 三套模板使用真实房间各导出一份 PDF，核对中文、目录页码与页脚编号。
- 全量 `pytest` 与 `scripts/verify.ps1` 在正常环境执行；本版本开发环境因沙箱文件删除限制仅跑定向测试。
