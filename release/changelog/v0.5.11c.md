本次更新补齐深渊帷幕的触手控制，并修正「高度随机性」的语义。

## 新增「触手大小」

变更时间：2026-11-03 10:34

- 主题契约新增 `tentacleSize`：范围 0.7–1.3，步进 0.05，默认 1。
- 只缩放整根触手的粗细 / 体量（根部半宽 `widthRatio`），不参与长度计算，与「触手密度」「触手高度」「摆动速度」彼此独立。
- 默认值 1 与升级前观感一致。
- 渲染端增加保护钳制：`MIN_WIDTH_RATIO = 0.048`、`MAX_WIDTH_RATIO = 0.175`，极端值下不会细到看不见，也不会糊成一团遮住法阵与聊天区。
- 旧配置缺少 `tentacleSize` 时回落到 1，不报错。

## 修正「高度随机性」语义

变更时间：2026-11-03 10:34

- 原实现的问题：`t.lengthRatio = length * tentacleHeight * (1 + rand(-1,1) * variance)`，而 `length` 本身就是每根触手的随机长度（底部 0.44–0.8、内圈 0.5–0.64 等）。即使方差为 0，高度仍被另一处随机长度扰动，无法真正平齐。
- 新实现：为每种位置类型设固定基准高度 `BASE_HEIGHT`（底部内圈 0.57、底部外圈 0.62、侧肢 0.49–0.78、顶部 0.28–0.32），随机扰动只叠加在高度方向：`length * tentacleHeight * (1 + rand(-1,1) * variance)`。方差为 0 时扰动严格为 0，同一排触手完全平齐。
- 随机数仍由固定种子 `createSessionRandom(0x7e11)` 驱动，同参数下可复现；每次重建都消费一次高度随机数，调节方差不会打乱宽度 / 摆动相位序列。
- 观感三档：`0` 平齐如帷幕边；`0.2`（默认）轻微高低差；`0.5` 明显错落。
- 旧值按原值直接沿用（不归一化），但由于基准从随机长度改为固定高度，同数值会比旧版更规整；如需保持旧观感可将该值上调约 0.05–0.1。

## 已知限制

- 高度随机性只保证同类触手平齐；底部、侧肢、顶部仍按各自的基准高度排列，因此方差为 0 时整体画面不会是所有触手同一高度。
- 触手大小是全局参数，不区分底部 / 侧肢 / 顶部，极值下侧肢的体量变化也会同步放大。
- 旧配置的 `tentacleHeightVariance` 语义变化不改存储值，观感可能比旧版略规整。
