# v0.5.3b

发布日期：（待发布）

本次更新重构全局配置加载为四层优先级（代码默认值 < 包内模板 < 用户配置 < 环境变量/CLI）：仓库与发布包只携带 `config/templates/` 模板，`data/config/` 在首次启动时从模板幂等生成，本地测试配置不再入库；同时把随包参考数据 `character_skills.json` 移出配置目录。

## 分层配置加载（Phase 0）

- 新增 `trpg_server/config/` 包：`paths.py`（配置目录解析与 CLI 覆盖注入点）、`fields.py`（FieldSpec 与 bool/int/枚举/文本转换器）、`schema.py`（全部配置项的权威规格表，`AIRuntimeConfig` 自 `agents/config.py` 迁入）、`sources.py`（tomlkit 读取、嵌套表扁平化、`AI_TRPG_CFG_*` 环境变量收集）、`merge.py`（逐层类型化 + 叶子键覆盖合并 + 默认值兜底 + 加载缓存）、`writer.py`（注释保留的定点写入与原子替换）、`bootstrap.py`（首次启动种子复制，绝不覆盖已有文件）。
- 加载优先级：代码内默认值 < `config/templates/general.toml` < `data/config/general.toml` < 环境变量 `AI_TRPG_CFG_<段>_<键>` < CLI 覆盖；某层非法值只丢弃该层该键，回退下一层，不再污染其它层或让启动失败。
- `agents/config.py` 重写为薄门面，保持 `load_ai_runtime_config` / `write_ai_setting` / `AIRuntimeConfig` 公共 API 不变，全部消费方（16 个文件）无需改动。
- `ensure_user_config()` 接入 `server.py` 与 `app_factory`：首次启动生成 `general.toml`、`roles/kp.md`、`roles/debug-kp.md`、`aiplatform/default-request.json`；`permissions.json`、`roles.json` 与平台配置不预生成，首次保存时写入。
- 新增依赖 `tomlkit`（MIT）：TOML 往返解析保留注释、键序与空白，写入侧与读取侧复用同一解析器；已登记 `THIRD-PARTY-LICENSES.md`。

## 模板与文件迁移

- `data/config/general.toml` → `config/templates/general.toml`：补齐头部优先级说明注释、`[ai]` 段 `dice_physics_results` / `dice_reroll_mode` / `dice_reroll_limit`、`[site_agent]` 段 `action_ttl_seconds` / `max_conversations_per_user` / `max_messages_per_conversation`；模板值即首次部署的默认配置。
- `data/config/roles/kp.md`、`debug-kp.md` → `config/templates/roles/`；`data/config/aiplatform/default-request.json` → `config/templates/aiplatform/`。
- `data/config/character_skills.json` → `data/character_skills.json`：它是随包规则参考数据而非用户配置，与 `data/occupations/`、`data/weapons/` 同级；三位读者（角色 AI、角色路由、骰子工具）统一改用 `settings.CHARACTER_SKILLS_FILE`。
- `.gitignore` 新增 `/data/config/`：`network.json`、`penetration.json`、`site.json`、`roles/roles.json`、`aiplatform/*.json`、`aimodel/**` 等本地测试配置脱离跟踪（磁盘保留），发布包不再携带。

## CLI 参数与配置控制台命令（Phase 3）

变更时间：2026-10-22 14:58

- `server.py` 新增命令行参数：`--config-dir <PATH>`（整体改换配置目录，首次启动的种子文件也生成到该目录）、`--set section.key=value`（最高优先级覆盖，可重复，段名支持点号如 `network.penetration.settings.auth_token=x`）、`--port <N>`（显式端口形式，与位置参数同现时 `--port` 胜出）；未知参数直接报错退出，避免拼错被静默忽略。

- 端口选择优先级收敛为：CLI > 环境变量 > 用户配置 > 模板/代码默认。
- 新增 `config_admin.py` 控制台模块与三个控制台命令：`config show [--section <name>]`（查看五层合并后的生效配置，锁定键标注 `(locked: env/cli)`）、`config migrate [--yes]`（把遗留 `site.json`/`network.json`/`penetration.json` 中 TOML 尚缺失的键并入 `general.toml`，原文件改名 `*.legacy`；只写缺失键保证迁移前后生效配置一致；缺省预演，遵循破坏性命令确认约定）、`config path`（打印配置目录/模板目录/用户配置文件路径）；`command_help_text()` 与 `docs/console-commands.md` 已同步。
- 新增 `tests/test_config_console.py` 28 例：CLI 解析各形态与非法输入、全局 CLI 覆盖注入与清除、迁移预览/执行/改名前后生效配置一致、控制台 dispatch 的预演/取消/--yes 路径；`test_small_model_config.py` 中针对已删除前端 TOML 解析器的旧断言改为「使用 JSON API」回归守卫。
