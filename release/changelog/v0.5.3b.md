本次更新重构全局配置加载为四层优先级（代码默认值 < 包内模板 < 用户配置 < 环境变量/CLI）：仓库与发布包只携带 `config/templates/` 模板，`data/config/` 在首次启动时从模板幂等生成，本地测试配置不再入库；同时把随包参考数据 `character_skills.json` 移出配置目录。

## 分层配置加载（Phase 0）

- 新增 `trpg_server/config/` 包：`paths.py`（配置目录解析与 CLI 覆盖注入点）、`fields.py`（FieldSpec 与 bool/int/枚举/文本转换器）、`schema.py`（全部配置项的权威规格表，`AIRuntimeConfig` 自 `agents/config.py` 迁入）、`sources.py`（tomlkit 读取、嵌套表扁平化、`AI_TRPG_CFG_*` 环境变量收集）、`merge.py`（逐层类型化 + 叶子键覆盖合并 + 默认值兜底 + 加载缓存）、`writer.py`（注释保留的定点写入与原子替换）、`bootstrap.py`（首次启动种子复制，绝不覆盖已有文件）。
- 加载优先级：代码内默认值 < `config/templates/general.toml` < `data/config/general.toml` < 环境变量 `AI_TRPG_CFG_<段>_<键>` < CLI 覆盖；某层非法值只丢弃该层该键，回退下一层，不再污染其它层或让启动失败。
- `agents/config.py` 重写为薄门面，保持 `load_ai_runtime_config` / `write_ai_setting` / `AIRuntimeConfig` 公共 API 不变，全部消费方（16 个文件）无需改动。
- `ensure_user_config()` 接入 `server.py` 与 `app_factory`：首次启动生成 `general.toml`、`roles/kp.md`、`roles/debug-kp.md`、`aiplatform/default-request.json`；`permissions.json`、`roles.json` 与平台配置不预生成，首次保存时写入。
- 新增依赖 `tomlkit`（MIT）：TOML 往返解析保留注释、键序与空白，写入侧与读取侧复用同一解析器；已登记 `THIRD-PARTY-LICENSES.md`。

- 严格鉴权：设置读写额外要求 ADMIN/OWNER（即使权限矩阵把 `settings.general` 授予 USER 也不放行）；`network`、`network.access_control`、`network.penetration`、`network.penetration.settings`、`site_agent` 段仅 OWNER 可改；穿透令牌等密钥字段读取打码、写入拒绝；被环境变量/CLI 锁定的键拒绝写入。房间消息工具在 preview 与 apply 两处分别校验房主/房间管理员身份。
- 待确认操作新增 `room_id` 持久化：房间级写操作在用户确认后仍能通过 `scope=room` 鉴权。
- 房间 AI 用量统计：新增 `room_usage.py`，每次带 `room_id` 的 AI 调用按平台配置的模型单价（`input_price` / `output_price`，每百万 token）与 `config.currency` 累加到房间 `usage.json`（总 token、缓存 token、调用次数、分模型明细、多货币花费）；`telemetry.record_ai_usage` 统一挂钩，未配置单价时只统计 token。
- 房间用量接口与可见范围：新增 `GET /api/rooms/<room_id>/usage`；房间详情、房间列表与创建/加入房间响应仅在请求者是房主/房间管理员（或站点管理员）时附带 `usage`。
- 前端：AI 平台配置新增模型输入/输出单价与币种（CNY/USD/EUR/JPY）；房间标题栏右上角显示 `本房间累计 N tokens · ¥X` 小字，房间管理卡片与房间信息卡同步显示；`new_message` 后自动刷新用量，`room_messages_changed` 后自动重载消息列表。
- 修复：网站 Agent 的待确认操作此前只识别 `action_args`，而各工具预览返回的是 `apply_args`，导致确认后可能用模型原始参数落盘；现在两者都支持，并优先使用预览整理后的参数。
- 修复：读取网站设置时，点号段名（如 `network.penetration.settings`）位于顶层键，原实现只查嵌套结构，导致穿透令牌等密钥未被打码；现在优先匹配顶层段名，密钥读取与写入均严格拦截。
- 新增回归测试：`tests/test_room_usage.py`（单价计费、多币种、累加、损坏文件回退、telemetry 钩子）与 `tests/test_site_agent.py` 的设置鉴权、密钥打码、房间消息权限、确认参数、个人资料校验用例。
- 后端 `pytest` 全量 603 passed；前端 `npm run typecheck` 与 `npm run build:frontend` 通过。
