# v0.5.13c

## 实时配图 3A：AI KP 决策触发与状态可见

改动时间：2026-11-03 13:15（Asia/Shanghai）

### 玩家可见变化

- 回答生成时，聊天区「正在思考」位置会出现「KP 正在判断是否需要配图…」与「正在配图…」阶段提示。
- 右下角配图面板会显示「等待场景推进」「正在配图…」「正在切换场景并配图…」「本轮无需配图」「配图失败：原因（可点击重新配图重试）」。
- 以上状态通过既有 socket 事件广播，房间内所有玩家同步看到，不再只有管理员可见。
- 普通玩家只读，不显示「重新配图」按钮，也不能触发任何生图调用。

### 触发档位

`immersive.illustration_trigger` 四档，默认 `important`：

| 档位 | 语义 |
| --- | --- |
| `off` | 关闭自动配图 |
| `important` | 仅重要场景转换（默认） |
| `turn_interval` | 每 N 回合（N 由 `illustration_min_turns` 决定） |
| `frequent` | 频繁（每回合都可能） |

分层：字段默认 < 站点默认（`illustration_trigger`）< 个人覆盖（受 `illustration_trigger_allowed` 限制，`off` 始终允许）< 房间收紧（`immersive_illustration_trigger` 只接受 `important` / `off`）。房间只能收紧，不能放宽。

### AI KP 决策链路

- 复用既有 AI 平台解析与请求构造：`resolve_ai_target` + `build_request_payload` + `post_with_retry`，带超时（`illustration_kp_timeout`）与独立每日预算（`illustration_kp_daily_budget`）。
- KP 输出严格校验（`should_illustrate` 必须布尔；需要配图时必须给出 `scene_prompt`），非法结构按规则降级。
- 决策在后台线程执行，每房间单在途；超时、异常、预算耗尽都只记录日志并回退到规则档位，不阻塞叙事、不向玩家抛错。
- 规则降级：`important` 只有在重要场景信号时出图；`turn_interval` / `frequent` 到点即出；提示词由本地场景分析生成。
- 自动生成仍受既有 `illustration_min_turns`、房间每小时上限、每日生图预算与并发闸门约束。

### 控制台

站点级（默认预演，`--yes` 执行）：

```
immersive illustration trigger <off|important|turn_interval|frequent>
immersive illustration allowed <a,b,...>
immersive illustration kp-budget <n>
immersive kp            # 查看 KP 今日调用/预算/平台
```

房间级：

```
immersive illustration trigger show
immersive illustration trigger <inherit|important|off> [--yes]
```

日志字段包含：触发来源、生效档位、KP 决策与理由摘要、提示词摘要、耗时、是否降级、预算/配额判定。
