# 帷幕 The Veil · 发布说明

**版本：1.0.5**

帷幕是一个可以自己部署的 AI 跑团（TRPG）平台：AI 当守秘人，你和朋友用浏览器进入同一个房间，掷骰、聊天、推进剧情。账号、剧本、聊天记录都保存在你自己的电脑上。

本文件面向使用者，说明怎么获取、解压、启动、备份与排查问题。发布包内**不包含**开发文档、测试与开发脚本。

---

## 一、获取发布包

1. 打开 [GitHub Releases](https://github.com/Nobook1121/The-Veil/releases/latest)，选择最新版本。
2. 下载 `the-veil-v1.0.5.zip` 与同名 `.sha256` 校验文件。
3. 可选：校验下载是否完整。

   Windows PowerShell：

   ```powershell
   Get-FileHash .\the-veil-v1.0.5.zip -Algorithm SHA256
   ```

   macOS / Linux：

   ```bash
   sha256sum the-veil-v1.0.5.zip
   ```

   输出应与 `.sha256` 文件中的值一致；不一致说明下载损坏，请重新下载。

发布包是解压即用的运行副本，不需要先安装 Node.js，也不需要联网构建前端。

---

## 二、解压与目录要求

1. **先完整解压**到本地磁盘，再运行。不要直接在压缩包的预览窗口里双击 `start.cmd`。
2. **路径建议不含中文与空格**，例如 `D:\TheVeil`。
3. 不要放在需要管理员权限的目录（如 `C:\Program Files`、`C:\Windows`）或系统盘根目录；也不要放在网盘同步目录里，避免文件被同步程序占用。
4. 当前登录用户需要对安装目录有**读写权限**：首次启动会创建 `.venv` 与 `data` 目录。
5. 请使用正常的桌面会话运行，不要从受限账户、沙箱或系统计划任务里做首次启动（依赖安装需要正常访问网络与用户目录）。
6. 预留磁盘空间：只运行平台约需 1 GB；如果还要使用本地 Embedding 向量模型，额外预留 1 GB 以上。
7. 同一个安装目录**只运行一个实例**。关闭启动窗口（或按 `Ctrl+C`）即停止服务。

## 三、启动

### Windows（推荐）

1. 双击解压目录里的 `start.cmd`。
2. 脚本会依次完成：
   - 检查 Python：需要 3.11 或更高版本；找不到时会自动下载并按「仅当前用户」静默安装，不需要管理员权限；
   - 在安装目录创建独立的运行环境 `.venv`，不影响系统里的 Python；
   - 安装运行依赖，失败时会自动更换依赖源重试；
   - 如果目录里带了本地 Embedding 模型，补齐模型运行依赖；
   - 检查前端页面产物，缺失时才尝试构建；
   - 以上都准备好后，启动服务。
3. 看到类似下面这一行即表示启动成功：

   ```text
   listening on http://127.0.0.1:8086
   ```

4. 打开浏览器访问该地址。**不要关闭启动窗口**，关掉窗口服务就停了。

### macOS / Linux

安装 Python 3.11+ 后，在解压目录执行：

```bash
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
./.venv/bin/python server.py
```

然后访问 `http://127.0.0.1:8086`。

### 为什么第一次启动要等很久

第一次启动通常需要几分钟，主要时间花在：

- 下载并安装运行依赖；
- **本地 Embedding 模型**：如果安装目录的 `data/runtime/models/embedding` 下放了向量模型（升级时保留 `data` 会带过来，或在首次向导里选择自动下载），脚本还要补齐 `sentence-transformers` 与 CPU 版 `torch`，并加载模型。这一项本身就有数百 MB，首次会明显变慢。

没有本地模型时不会下载这部分依赖，平台会使用内置的轻量向量方案，启动会快很多；语义检索效果会弱一些，可在设置里再配置。

第二次启动会核对已安装的依赖，齐全时直接跳过安装，通常几秒即可。

### 首次打开后的向导

系统里还没有管理员账号时，打开首页会自动进入向导：配置 AI 平台 →（可选）准备 Embedding 模型 → 站点名称 →（可选）域名 →（可选）实时配乐 / 配图 / 语音 → 创建 Owner 账号 → 进入系统。

三项可选功能默认关闭，避免首次运行就产生外部调用或费用，之后可在「设置 → 实时沉浸」里开启。

## 四、端口与访问地址

- 默认端口 **8086**，本机访问 <http://127.0.0.1:8086>。
- 8086 被占用时，程序会自动向后寻找空闲端口（约 8086–8099）。**以启动窗口里实际打印的 `listening on` 地址为准**。
- 同一 Wi-Fi 下的朋友使用窗口里打印的局域网地址，形如 `http://192.168.1.23:8086`；首次启动时 Windows 防火墙可能弹窗，请选择允许访问。
- 异地联机请使用内网穿透或异地组网工具，不要直接把端口裸露到公网，也不要关闭登录验证。
- 需要固定端口时，在安装目录打开 PowerShell 运行：

  ```powershell
  .\start.cmd 8090
  ```

## 五、配置与数据目录

所有内容都在安装目录的 `data` 文件夹里：

| 位置 | 内容 |
|---|---|
| `data/config/general.toml` | 主配置：站点名、网络与端口、AI 平台、功能开关；**含 API Key，不要分享或上传网盘** |
| `data/config/` | 其他配置与 AI 平台凭据，整个目录都不应对公网暴露 |
| `data/runtime/` | 账号、房间与聊天记录、角色卡、日志、向量索引、导出产物、模型缓存 |
| `data/scenarios/` | 剧本与示例剧本 |
| `data/assets/` | 头像、剧本封面、背景音乐等上传资源 |

补充说明：

- 首次启动会用 `config/templates/` 里的模板生成 `data/config/general.toml`；要改配置请改 `data/config/` 下的文件，不要改模板。
- 运行日志在 `data/runtime/logs/`。
- 会话密钥通过环境变量 `AI_TRPG_SECRET_KEY` 提供，不要写进配置文件或分享出去。
- 大多数设置也可以在网页「设置」里修改，保存后按提示生效。

## 六、备份与迁移

**备份**：停止服务后，把整个 `data` 文件夹复制一份即可。程序文件可以随时重新下载，只有 `data` 是不可再生的。

**换电脑 / 迁移**：在新电脑解压同一版本的发布包，把旧电脑的 `data` 整个复制到新目录，再启动。

**升级**：

1. 关闭旧版本窗口，备份 `data`；
2. 把新版本解压到一个**新目录**；
3. 把旧目录的 `data` 整个复制到新目录；
4. 启动新版本，确认首页、账号与房间记录正常；
5. 确认无误后再删除旧目录。

不要用新版本直接覆盖旧目录，避免误覆盖 `data`。

## 七、插件与自定义道具模板

### 第三方插件

- 插件放在 `data/plugins/<插件 id>/`，启用列表是 `data/plugins/enabled.json`。
- 默认不启用；未启用的插件不会读取资源，也不会执行代码。
- 管理员可以在「设置 → 插件」里查看、启用、禁用与卸载。
- 需要临时全部禁用时，启动时加 `--no-plugins`，或设置环境变量 `TRPG_PLUGINS_DISABLED=1`。
- 插件代码以服务进程权限运行，**只安装你信任来源的插件**。

### 自定义道具模板

- 用户模板放在 `data/props/templates/<模板 id>/`，至少包含 `manifest.json`、`page.html`、`style.css`，可选 `assets/`。
- 放好后在道具编辑器里点「重新扫描」，无需重启。
- 模板只允许文档流标签与有限样式，不允许脚本、外链样式与符号链接；非法模板只会让自己不可用，不影响其他模板。

## 八、常见问题

**1. 每次启动都在安装依赖，正常吗？**

不正常。脚本会记录依赖指纹；指纹变化时会先逐条核对已安装的包，齐全就只刷新指纹并跳过安装，只有确实缺包才会重装。如果反复安装，通常是安装失败或目录不可写；查看窗口里的报错，或手动执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-bootstrap.ps1
```

需要强制重装时加 `-Force`，只查看计划不改动时加 `-DryRun`。

**2. 8086 被占用怎么办？**

程序会自动向后找空闲端口，以窗口里打印的地址为准；也可以指定端口：`.\start.cmd 8090`。不要为了腾端口去强杀不认识的进程。

**3. 第一次启动特别慢 / 像卡住了？**

首次要下载依赖；如果带了本地 Embedding 模型，还要下载 CPU 版 `torch` 与 `sentence-transformers` 并加载模型，几百 MB 起步。窗口没有报错时请耐心等待。之后启动只需几秒。

**4. 升级后浏览器还是旧界面？**

前端静态资源会被浏览器缓存。按 `Ctrl+F5` 强制刷新，或清除本站缓存 / 用无痕窗口打开；仍然不对时确认浏览器地址与启动窗口里的端口一致。

**5. 双击 `start.cmd` 提示「无法验证发布者」？**

常见原因是安装目录被打成了 **Low 完整性级别**（部分解压工具、沙箱或安全软件会这样做），Windows 会把脚本当作不可信文件。把目录标签设回 Medium 即可，在普通 PowerShell 或命令提示符里执行：

```powershell
icacls "<安装目录>" /setintegritylevel "(OI)(CI)Medium" /T
```

例如：

```powershell
icacls "D:\TheVeil" /setintegritylevel "(OI)(CI)Medium" /T
```

执行完重新双击 `start.cmd`。如果压缩包是从浏览器下载的，也可以先右键 zip →「属性」→ 勾选「解除锁定」再解压。

**6. 双击后窗口一闪就没了？**

多为 Python 或依赖安装失败。重新运行一次；仍失败时用上面的命令手动执行 `start-bootstrap.ps1`，保留窗口里的错误信息再排查。

**7. 朋友连不上我的地址？**

确认大家在同一网络、防火墙已允许该端口、朋友输入的是完整地址（含 `http://` 与端口）；异地联机请使用穿透或组网工具。

**8. AI 不回复或只回一半？**

检查 API Key、账户余额、Base URL 与模型名；在「设置 → 模型设置」里适当调大 AI 请求超时。

**9. 忘记管理员密码？**

在启动窗口（不是网页）里输入 `user list` 查看账号，再执行 `user reset-password <用户名>` 获取临时密码；输入 `help` 可查看全部控制台命令。
