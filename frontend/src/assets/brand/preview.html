帷幕 THE VEIL

以「守秘人手里的提灯」为母题：П 形提梁挂起一盏方形提灯，带檐的顶盖、分三格的灯身、比灯身略宽的底座与双脚，腔内是一枚尖顶火苗。提梁 / 带檐顶盖 / 底座三件在剪影里独立成立——不看细节也知道这是提灯，也就是「帷幕之后仍有一盏灯」。

几何基准

  • 圆心 (512,512)，画布 1024
  • 包围盒 280×576，上下留白 224 / 224
  • 灯身 224×348（高宽比 1.554）
  • 宽檐 280 = 1.250× 灯身
  • 底座 256 = 1.143× 灯身
  • 提梁宽 168，腿宽 36，顶块 176×40

小尺寸策略

  • 32 用 32 单位整数网格，16 单独用 16 单位网格重画
  • 32px 省掉竖框，只留 2px 火焰孔
  • 16px 只留五段剪影：提梁 / 帽 / 身 / 座 / 双脚
  • 三档单色下均为 1 个连通块，不碎开
