# 帷幕 The Veil · 图标设计说明

## 1. 母题

图标是**守秘人手里的提灯**：П 形提梁挂起一盏方形提灯，带檐的顶盖、分三格的灯身、比灯身略宽的底座与双脚，腔内一枚尖顶火苗。

选择它而不是「法规 / 眼 / 骰」的理由：品牌需要在**任意语境、不看文字**时被认成一件具体器物；提灯的剪影由三个结构信号撑住——**提梁（提）、带檐顶盖（帽）、底座与双脚（台）**——三者齐备时，即使看不清内部也仍是提灯。语义上它对应「帷幕之后仍有一盏灯」：AI 守秘人掌灯，玩家围绕光源展开叙事。

## 2. 几何构造（1024 母版）

全部落在整数网格，无手调、无渐变、无描边阴影、无 3D 光照；只用平面明度与负空间。

- 画布 1024×1024，底板圆角矩形 `32..992`，圆角 `224 = 7×32`。
- 整体包围盒 `x 372–652 × y 224–800`（280×576）→ 中心 `(512,512)`，上下留白 `224 / 224`（各 21.9%），左右 372 / 372。
- **提梁**：П 形，开口朝下。顶梁 `(428,224)–(596,264)`，宽 168 × 40；两条 36 宽的腿落到 308，压进顶块 36 单位，保证面积重叠（点接触在抗锯齿下会断块）。
- **顶块**：`424–600 × 272–312`（176×40）。
- **宽檐**：`372–652 × 312–364`（280×52）= 灯身 224 的 **1.250 倍**。
- **灯身**：`400–624 × 364–712`（224×348），高宽比 **1.554**；四边灯框 24 宽；玻璃面 `424–600 × 388–688`。
- **分格**：两根 24 宽竖框 `452–476` / `548–572`，玻璃被切成 28 / 72 / 28 三格（框条是结构，不是装饰）。
- **火焰**：尖顶 `(512,450)`、平底 590、最宽 60、高 140；作为 pane 的负空间挖空，透出后面预置的亮芯椭圆 `(512,550) rx 108 / ry 140`。
- **底座**：`384–640 × 712–776`（256×64）= 灯身 **1.143 倍**；双脚各 40 × 24。
- **光晕**：圆 `(512,528) r 248`，只用来把灯从深底上托起一层，不参与轮廓。

视觉重心：包围盒中心精确 `(512,512)`；单色剪影的等权墨量重心实测 `(512,514)`（+2，约为图标高度的 0.35%）。提灯天然下重（底座 + 灯身），靠「提梁 + 顶块 + 宽檐」的上部墨量把偏差压到 2 单位内。

## 3. 小尺寸策略

- `icon-simple.svg`：**32×32 整数网格**（1 单位 = 1px），用于 32 与 48px。bail 4×1 → 帽 6×2 → 宽檐 8×1 → 身 6×11 → 座 8×2 → 双脚 2 个 1×1。32px 省掉竖框（4px 玻璃里两根 1px 框会糊），只留 2px 火焰孔；底座故意做成与檐同宽 8，让「上宽 8 / 中窄 6 / 下宽 8」在 18px 高度里仍成立。
- `icon-16.svg`：**16×16 整数网格**，favicon 专用，独立重画而不是缩放。提梁 2×1 → 帽/檐 6×2 → 身 4×7 → 座 6×1 → 双脚 2 个 1×1；玻璃、竖框、火焰全部删掉——1px 里它们只会把灯身涂成一团。
- 三档在纯黑剪影下均为 **1 个连通块**（256px 7490px² / 32px 98px² / 16px 50px²），不碎开。

母版用于 128px 以上的头像、社交分享与印刷；32px 以下一律走简化版（PNG 与 favicon 已按此分配）。

## 4. 配色与背景

| 名称 | 值 | 用途 |
| --- | --- | --- |
| 褐夜 | `#17110A` | 底板 |
| 光晕褐 | `#3A2A12` | 底板内的光晕圆 |
| 琥珀 | `#E0A94B` | 提梁 |
| 麦白 | `#F6E7C4` | 顶块 / 宽檐 / 底座 / 双脚 |
| 灯身 | `#E8D3A8` | 灯框与竖框 |
| 玻璃 | `#5C4218` | 玻璃面（暗的中调） |
| 亮芯 | `#FFE9B0` | 火焰后方的亮芯 |
| 骨白 | `#E8E0CD` | 单色版默认色 |

主色版自带褐夜底板，因此在**深色与浅色页面**上都靠底板与麦白边线保持对比，无需为背景另做反白版本；暖色（琥珀 / 麦白）比冷蓝更适合浅色页面。
单色版透明底、全部取 `currentColor`，可直接用于压印/水印/群头像；内联时改 `svg { color }` 即可整体换色。

## 5. 文件与落位

源文件：`frontend/src/assets/brand/`

| 文件 | 说明 |
| --- | --- |
| `icon.svg` | 1024 方形母版 |
| `icon-simple.svg` | 32×32 整数网格简化版（32 / 48px） |
| `icon-16.svg` | 16×16 整数网格独立重画（favicon） |
| `icon-maskable.svg` | 满版背景 + 内容缩放 1.20（最远点 r386，位于 80% 安全圆 r409.6 内） |
| `icon-mono.svg` | 透明底单色版（`currentColor`） |
| `icon-{512,256,128,64}.png` | 母版栅格 |
| `icon-{48,32,16}.png` | 简化版栅格（48/32 用 icon-simple，16 用 icon-16） |
| `icon-maskable-512.png` / `icon-mono-256.png` | 可遮罩 / 单色示例 |
| `favicon.ico` | 16/32/48，32bpp BMP + AND 掩码（兼容旧平台） |
| `apple-touch-icon.png` | 180×180，满版不透明 |
| `preview.html` | 深/浅背景与 16/32/64/128 并排验收页 |

构建落位：`scripts/build-frontend.mjs` 的 `copyBrandAssets()` 把上述资源复制到
`dist/public/assets/brand/`，并把 `favicon.ico`、`apple-touch-icon.png` 放到 `dist/public/` 根。
`index.html` 头部已加入：

```html
<link rel="icon" href="/favicon.ico" sizes="16x16 32x32 48x48">
<link rel="icon" type="image/svg+xml" href="/assets/brand/icon-simple.svg">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
```

`gh-pages` 工作树同步放入 `assets/brand/` 与根级 favicon，落地页 `index.html` 使用同一组 `<link>`。

## 6. 导出与验收

```powershell
python scripts/export-brand-icons.py
```

- 用本机 Microsoft Edge（Playwright，`deviceScaleFactor=1`）按目标像素逐张截图，保证 PNG 尺寸精确；
- ICO 由脚本内置的 PNG 解码 + BMP 打包生成，不依赖 Pillow；
- 脚本会做 XML 解析、PNG 尺寸、透明角、覆盖率与 ICO 条目检查。

验收截图：`.screenshots/brand/preview-panel-dark.png`、`preview-panel-light.png`、`preview-full.png`。
