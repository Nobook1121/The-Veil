欢迎，先完成初始化

这是首次部署，请按步骤完成基础配置，之后即可正常登录使用。

1. 配置 AI API

填写兼容 OpenAI 协议的接口地址、API Key 与模型名。API 地址需指向 chat completions 接口。

2. 为网站取名

这个名字会显示在浏览器标题栏和侧边栏。

3. 绑定域名（可跳过）

仅记录域名用于展示。实际的 DNS 解析与 HTTPS 需要由 Nginx/Caddy 等反向代理完成，可稍后再配置。

4. 创建 Owner 账号

这是最高权限账号，用于管理网站。用户名 3-32 位，密码至少 8 位。

5. 完成

初始化已完成，点击下方按钮进入系统。
