# 凡戴尔的失落矿坑（D&D 5e）模组包

本目录是一个可直接被《帷幕》识别的剧本目录，规则集为 `dnd5e`。

- 数据来源：<https://5e.kiwee.top/adventure.html#lmop> 及其子页面（5etools 中文资料站的 LMoP 条目）
- 地图作者：Mike Schley（地图图片取自上述页面，已按本地使用需要压缩尺寸）
- 整理日期：2026-11-18
- 收录范围：四部分主线、凡达林小镇地点、支线地点、附录 A/B 索引
- 未收录/缺项：见下方“缺项说明”，没有用记忆补写页面不存在的内容

## 如何导入 / 被识别

本包采用程序现有的“剧本目录”识别方式：

1. 将整个 `scenario-lmop-5e-001` 目录放在 `data/scenarios/` 下（当前工作区已经放在该位置）。
2. 启动或刷新《帷幕》，在剧本列表 / 创建房间时选择“凡戴尔的失落矿坑（D&D 5e）”。
3. 创建房间时规则集选择 `D&D 5e`；`scenario.json` 已声明 `ruleset_id: dnd5e`，不依赖站点默认规则集。
4. 进入房间后，地图会在进入对应地点时作为场景附件自动展示；如需把地图设为 canvas 背景，请在房间地图设置中使用“导入地图”选择 `assets/maps/` 下的同一张图片。

不需要额外导入工具，也不需要修改环境变量。

## 缺项说明

以下内容在源页面中就没有展开或明确不提供，本包没有自行编造：

- 怪物数据卡在页面中引用自附录 B / 规则书；本包只保留怪物索引与“数据卡”指引，没有重写数值。
- 附录 A 的魔法物品在页面中只列出名称与通用规则，具体物品描述引用外部魔法物品数据。
- 阿加莎的巢穴、古枭井、飞龙突岩在页面中明确“没有提供地图”。
- 页面没有独立的“线索”清单；本包中的线索条目由页面原文相关段落整理，并在条目内保留来源小节标题。

## 网页端 Agent 能力核对（摘要）

- 已接通：房间 KP Agent 按 `dnd5e` 规则集下发 `dnd5e.roll_check`、`combat.*`、`spell.*`、`effect.*`、`scene.advance` 等工具；角色卡编辑器有独立的 5e 卡面；地图插件有导入 UI 与 `veil-map.move_token`。
- 未接通：网站 Agent 的工具清单没有地图导入/地图写入，也没有 `dnd5e` 专属工具；剧本创作模式提示词仍写死 CoC 7e；`scenarios.import_script` 没有 `ruleset_id` 参数；网站 Agent 不能调用插件的 `agent_tools`。
